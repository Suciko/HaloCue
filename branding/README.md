# HaloCue brand assets

The maintainer selected the original “跃入” concept on 2026-10-03: a blue rounded tile, tilted white ring and cyan cue tail. It is an original HaloCue design, reused without changing its geometry or colors.

The local BA halo collection was research only; no game icon is copied or distributed.

`halocue-icon.svg` is the editable source. Run `python tools/build_brand_icon.py` with CairoSVG and Pillow to regenerate the transparent 1024 px PNG, 64 px favicon, Windows ICO sizes 16–256 px, writing favicon and Electron boot SVG copy. Other icon files are generated artifacts; change the master SVG first.
