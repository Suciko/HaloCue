# HaloCue brand assets

The HaloCue icon is an original “halo + cue” mark: a dark navy core, white cue triangle, three asymmetric cyan arcs, two alignment ticks, and one coral cue dot.

The local BA halo collection was used only to understand generic halo visual language. It is neither copied nor distributed with HaloCue.

`halocue-icon.png` is the transparent 1024 px master. `halocue-favicon.png` is the 64 px web favicon, and `halocue.ico` contains the Windows application sizes from 16 px through 256 px.
