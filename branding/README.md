# HaloCue brand assets

The HaloCue icon is an original, compact “halo + cue” mark. An open C-shaped halo frames a white H; a warm point marks the next creative cue. The dark rounded tile keeps the mark legible on light and dark desktops without a glow or hairline detail.

The local BA halo collection was used only to understand generic halo visual language. It is neither copied nor distributed with HaloCue.

`halocue-icon.svg` is the editable source. Run `python tools/build_brand_icon.py` with CairoSVG and Pillow to regenerate the transparent 1024 px `halocue-icon.png`, 64 px `halocue-favicon.png`, the Windows `halocue.ico` sizes from 16 px through 256 px, and the writing app's favicon copy. The PNG and ICO files are generated artifacts; change the SVG first.
