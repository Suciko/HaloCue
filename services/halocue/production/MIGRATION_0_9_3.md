# HaloCue 0.9.3 到 1.0 制作工作台迁移状态

本文只记录“已有剧本到 AA 工程”的制作链。写作工作台位于独立工程；素材工作台的历史素材、批量标注和跨项目复制等待工作台合并后再迁移。

## 已接入

- 剧本结构解析、角色识别与冻结发布版本
- 0.9.3 兼容的 PerformanceDraft、稳定卡片 ID 与版本冲突检查
- 角色映射、卡片增删改和移动、背景与音效请求处理
- AI 初审、AI 演出生成、演出建议记录与失败恢复状态
- 确定性编译、安装预检、安装和构建快照
- 本任务自定义素材的上传、校验、登记和编译携带
- CG 段落、CG 素材边界与用户选区后的 AI 制作意见
- 本地 TXT/Markdown 剧本导入
- AzureArchive 程序、安装目录和 data 工作区的只读检测与显式采用
- 持久化后台任务、重启中断标记、关联任务跳转和排队取消
- 可迁移的制作流程状态导航、动态审查路径与任务总览

## 下一批制作功能

- 多模型连接、模型列表、用途分配与运行环境诊断
- 可恢复任务的检查点详情和针对失败阶段的重新提交
- 官方资源索引的建立、更新状态和局部失败说明
- 本机最近剧本和最近 AA 项目入口
- 音效试听与构建后工程摘要

## 合并后迁移到素材工作台

- 历史素材浏览与复制到当前项目
- 跨项目素材副本履历
- 背景批量标注、角色表情分析与人工标签覆盖
- Spine WebGL 骨骼预览和批量渲染
- 素材分类、系列共用标记和来源管理

## 明确不迁移

- 旧版单页 UI 和旧 `/api/*` 路由外壳
- 浏览器传入任意本机路径读取剧本
- 未登记素材绕过项目白名单直接进入编译
- 强制终止正在写草稿或构建文件的后台线程
