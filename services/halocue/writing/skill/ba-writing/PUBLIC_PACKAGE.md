# HaloCue bundled BA writing rules

Maintainer authorized inclusion of publicly shareable writing rules on 2026-09-14.
This package began as the 16-file runtime rule subset of the previously used immutable
WritingPack snapshot `7059aecc3a7a7f5426239137580a8562f311ea7c39a6712d0a7420b60616dd76`.
A project-specific directory example has been replaced with a generic placeholder.
No character cards, official story corpus, user drafts, credentials, or assets are included.

That scope applies to this writing-rule directory. The separately authorized
`data/reference-pack/` now supplies curated character cards and losslessly
compressed official staging references (maintainer authorization, 2026-10-02).
See its README and manifest for scope, provenance and ownership.

The application supplies runtime context and exposes model outputs as proposals.
File-system/CLI workflows described in the source rules are reference methodology;
they do not grant the model tools or permission to write formal revisions directly.
The optional engine-script contract is not present in this source snapshot.

The 2026-10-07 productized revision adds original comedy and audience guidance
in `knowledge/二创喜剧与传播.md` and connects it to discussion, planning, drafting,
scoped edits and review. It distinguishes evolving callbacks from empty repetition
and respects the author's serious/cozy genres. The WritingPack version is
`ba-writing.productized/1.1.1`; the runtime records exact source fingerprints.
Private analyses and extracted scripts remain external research, not shipped
examples. Maintenance and verification are recorded in
`docs/handoffs/2026-10-07-1.0-writing-comedy-prompts.md` in the HaloCue repository;
this product fork does not modify the external upstream Skill or its blind tests.
