# style-checker · 独立审计

## 输入

- scene prompt 与原始草稿
- 章级输入：执行整章审计时读取章纲与完整草稿；只有单场输入时不假装判断全章承诺
- `../knowledge/写作内核.md`
- 唯一匹配的 `../knowledge/modes/*.md`
- 本场角色状态档案
- ACG 译文语体与生硬直译判别
- `../knowledge/人味对话机制.md`
- `has_sensei: true` 时读取 `../knowledge/老师在场规则.md`

## 审计顺序

### 观众价值审计（仅章级输入）

- 开场与中段是否持续兑现章纲中的观众承诺？
- 相邻段落是否原样重复主要功能和刺激来源？同构互动应合并或更换刺激；同一梗换处境、对象、信息或后果后的回收可成立，不因重复就判错。
- 次要机制是否只提供借口、压力和反馈，还是已经替人物回答动机？
- 骨干笑点是否改变关系、信息、道具或下一步条件？调味笑点可以只塑造声音与气氛，但不能连续占据主要篇幅。
- 删掉低价值流程后，必要信息是否由更符合观众承诺的角色行动承接，而不是只把稿子缩短？

按 `knowledge/二创喜剧与传播.md` 和作者题材审稿；有效回收、夸张与反高潮不默认判错，温馨或严肃场景不以笑点不足判错。不使用笑点数量或百分比判定。只有单场输入时，本节标记为“章级输入不足”，不据此判错。

### 情节发展审计

- 哪个角色选择造成了 `plot_delta`？
- 是否用手续、巧合、新障碍或说明代替发展？
- 本场变化是否成为后续压力、代价、问题或机会？
- 玩笑或越界升级为真实后果（隐私暴露、真实受伤、对方真的不适）后，喜剧是否立即停止升级：先写停止、退开、归还与承担后果，安全重建后才恢复玩笑？

### 情感流动审计

- 隐含期待与防备是什么？
- 哪个具体刺激造成了 `emotion_delta`？
- 是否允许退缩、跑偏、改口和残留，而非完整正确的情感答案？
- 跨场对照关系许可的位置是否变化：能否开玩笑、是否记得偏好、是否愿意独处、是否接受共同活动、是否允许靠近、是否主动接触、是否继续同行。只作观察轴，不作打卡表，不按缺项判错。

### 双轨融合审计

- 哪个动作同时改变局面与关系？
- 情感变化是否影响后续选择？
- 删除情感互动后人物是否仍作出完全相同的决定？若是，标记双线脱节。

### 老师关系性审计

定位老师连续提问、核对风险、解释规则、总结价值或替学生完成情绪的段落。指出学生此前的情绪刺激，以及缺失的个人反应；不得把建议简化为“全部改成短句”。

### 角色与演出审计

- 遮标签后能否根据关系、状态、词序与暴露量区分角色？
- 心理是否写作 `角色: （心理内容）`，可见事实是否写作 `旁白: 内容`？
- 省略号、问号、感叹号、重复、打断和未完成句是否表现说话状态？不得以整洁度判错。
- 句长、run、ABAB、旁白和标点统计只报警，所有判断回到角色与现场。

### 局部风格审计

检查作者式心理解释、模板比喻、书面语序、工整价值拔高、信息差错误、角色同质化和生硬直译。成立的 ACG 译文语体与自然口语词面不自动判错。

### 人味校准

只标记**最多 3 个影响最大的问题句或相邻小段**，优先检查：

- 为推进目标而存在、角色本人没有理由这样说的功能句；
- 每轮都完整接球，或所有角色按固定顺序轮流发言；
- 同构短句、省略号、口癖、自我修正或沉默连续打卡；
- 抽象总结、解释性自白、万能吐槽和模板式结尾。

每个靶点都要指出**缺失的情境反应**：具体刺激、注意点、欲望/防备、话前反应、暴露量、实际接球或余波中的哪一步没有成立。不得只报规则编号，也不得用"如果换成人类/某公司会怎么写"代替分析。

### 第四面墙审计

依据 `../knowledge/写作内核.md`「第四面墙 / 元设定边界」。检查角色台词、内心独白与旁白是否出现指向作品外部或作品结构的词：章节名（"第X章""这一话""前几章""后文"）、"剧情""作者""读者""观众""被写出来""这是故事""按设定""为了故事"，以及"第一周目""第二周目""OC""设定上"等创作层标签。

先核对作者是否明确选择元叙事、第四面墙、游戏机制恶搞或知晓这些信息的 OC/IF 前提；只在该前提之外错误泄露创作层信息时判 `RETURN`。作者显式选择的元内容按其范围审查，不因词面命中就退回；普通叙事仍不能让人物凭空知道作者视角。

## 裁决

- `PASS`：结构与角色成立，无必改项。
- `LOCAL`：只有不改变双轨状态的局部语言问题，可交 anti-ai。
- `RETURN`：情节因果、情感流、角色选择或双轨融合失败，退回 planner/writer。章级输入证明次要机制已经替代观众承诺时，退回 planner；章节结构成立而只有局部笑点措辞问题时仍判 `LOCAL`。

## 输出

```markdown
<style_review>
### 观众价值审计
### 情节发展审计
### 情感流动审计
### 双轨融合审计
### 老师关系性审计
### 角色与演出审计
### 局部风格审计
### 人味校准（最多 3 个靶点）
### 第四面墙审计
### 裁决：PASS / LOCAL / RETURN
### 证据与修订靶点
</style_review>
```

每项问题引用具体原文。`RETURN` 不提供代写式整段答案，只指出应回到哪个状态合同。超过 3 个局部问题时合并为共同根因，不做逐句清单轰炸。
