# 提示词组装 SOP

1. 读取场景卡的七项双轨字段，不改章纲。
2. 按“项目私设 → 最新角色/社团写作档案 → 旧官方基线”加载涉及角色和社团。若同属一个社团的多个角色同场出场，应按需加载并合并社团群体接话链与社团OOC红线。只抽取本场相关的状态、关系、语言和 OOC 边界。
3. 可选检索一项叙事功能参考和一项情感状态参考；来源不可靠时省略，不伪造官方例子。
4. 按场景类型加载必要规则摘要，不全量注入 spec，不给句长、标点或情绪切换配额。
5. **场景条件化注入**（由 emotion_delta / 收尾形态触发，不全文照搬 spec）：
   - 当本场 `emotion_delta` 含“被击中 / 震撼 / 灵感爆发 / 兴奋失控”时，必须摘要注入：被击中型兴奋用**短句爆破 + 悬念递进弧**（认不出→怀疑认得→确认认得→慌乱翻找），每句一个信息单位；**禁止**一开口报菜名或进入成段美术技法解说——技法细节只能作为角色蹲下创作时零碎浮出的内心独白片段，一句一断。写成连贯鉴赏稿即失败。
   - 当本场收尾含“事后道歉 / 自我总结 / 为失态收场”时，必须摘要注入：**角色不得在现场总结自己的角色弧光或概括本场主题**；道歉只聚焦一个具体行为，不剖析动机、不总结失败；主题由行为自然呈现，不需角色替观众点明。
   - 当本场含“玩笑或试探升级为真实越界/伤害”的拍点（隐私暴露、真实受伤、边界被踩实、对方真的不适）时，必须摘要注入：真实后果出现的一拍起停止喜剧升级，先写停止、退开、归还与承担后果，反应速度本身就是人设；安全重建前不恢复玩笑，不用笑话盖过伤害。
   - 以上三条只以**功能机制描述**注入，不搬运官方成品句骨架、停顿或标点。人物名、地名、道具名、作品名与维持同一剧情所需的专有设定不是语言泄露，必须保留。
   - 当真人反馈出现“复述画面、老师只递话、上句不接下句”，使用 `literary_voice_v4_2`，在场景卡填写 2—6 项 `information_ownership` 与 2—6 项 `exchange_chain`。前者把每项事实绑定到首次载体和随后用途；后者把每轮绑定到上一刺激、响应者和实际变化。只写事实与因果，不预写台词，不把剧情节点逐项翻译成问答。
   - 当 V4.2 的事实与话轮因果已改善，但老师仍像递话按钮或工作报告时，使用 `literary_voice_v4_3`。它继承 V4.2，并把当前学生的官方师生话轮与优秀二创老师语体分层注入：`bond_choice` / `main_story_choice` 只教接话方向及学生反应，`scene_dialogue` 教关系距离，`momotalk` 只教聊天节奏；老师完整句形由二创文学对白样本校准。未标 `sample_form` 的旧样本不进入老师参照层。
   - 当 V4.3 的人物声音与老师承接已成立，但 `official_script` 仍出现流程记录、重复画面或报告式旁白时，使用 `literary_voice_v4_4`。它完整继承 V4.3，只新增旁白信息载体层：先决定信息是否必须由文字承载，再决定是否写成 `旁白:`；相邻对白已经证明的内容不重复，连续操作压成改变局面的结果，不设旁白条数配额。汇编器从 `knowledge/few_shot/narration_bridge_v1.json` 按场景功能最多注入三组“前一句对白 → 旁白 → 后一句对白”，`official_script` 排除 `fanfic_prose`。
   - 当所用主笔模型出现零散老师金句疑似导致按钮式接话、需要单独判断时，可使用实验变体 `literary_voice_v4_4_c`。它完整继承 V4.4，只替换老师连续样本：移除动态选择的老师单句/话轮，改用一段逐行核验的连续二创对话；不增加抽象规则，不过滤学生或老师运行卡，不继承 V4.5/V4.6。该变体只用于同模型 A/B，人工结果出来前不晋升生产基准。
   - 当 V4.4 的旁白功能已改善，但对白仍反复用单独的“嗯／哦／啊”或复述对方最后一个名词占据节拍时，使用 `literary_voice_v4_5`。它完整继承 V4.4，增加“对白节拍承载”：独立一轮应承载态度、判断、疑问、选择或会改变下一句的迟疑；纯听见确认不单独占行，名词复述只有在重新理解、确认归属或暴露在意时才独立。短句按现场功能保留，不按字数禁止，也不强制改成长句。V4.5 还会在本场运行时切片中隐藏 `bond_choice` / `main_story_choice` 里老师的纯迟疑按钮，但不修改人物母卡，不过滤学生话轮或 `scene_dialogue`。
   - 当强模型在同一场景下仍把 V4.4/V4.5 写成“句句有功能、潜台词被说透、回收过于漂亮”的成品台词时，可用实验变体 `literary_voice_v4_6`。它保留 Plot Delta、学生官方声音、当前学生官方老师接话、V4.4 旁白选择与桥接样本，并使用一段逐行核验的连续二创老师对话；同时不注入 Emotion Delta、Residue、Ending Payoff、process beats、老师起始倾向、结构失败门、V4.1/V4.2/V4.5 层及通用微观验收门。V4.6 不替代人工判断，也不默认晋升生产基准；只有同场首次成稿经过人评后再决定。
6. `render_mode: engine_script` 时，把 [演出契约](../knowledge/演出契约.md) 的分层格式段注入 prompt，并声明本场不适用 official_script 行格式契约。
7. 使用 [场景prompt模板](../templates/场景prompt模板.md) 输出纯净 prompt。

预算顺序：场景事实与双轨状态 > 角色状态档案 > 官方功能摘要 > 防错红线 > 可选短例。

检查：`plot_delta`、`emotion_delta`、`residue`、角色当前关系和 OOC 红线不得缺失；`emotion_delta` 只能限定变化方向，不得替 writer 写出完整情感答案。
- 若本场触发上述“被击中兴奋”条件，检查注入是否含短路爆破约束、是否明确禁止鉴赏稿式解说。
- 若本场触发“道歉收尾”条件，检查注入是否含“角色不得自述弧光”红线、是否禁止把反差主题说出口。
