# 连续对话样本规范

`speech.voice_examples` 校准单句内的词汇、句长与语气；`speech.voice_sequences` 校准跨轮承接、话题惯性、延迟改口、关系距离和老师如何参与。两者互补，不能用一堆孤立名句代替连续话轮。

## 数据结构

每项必须来自同一个可追溯官方片段：

```json
{
  "source_id": "剧情或语音来源 ID",
  "phase": "可选；稳定的时间线、身体或身份阶段",
  "sample_form": "bond_choice | main_story_choice | scene_dialogue | momotalk",
  "context": "只说明这几轮开始时已经成立的现场关系与刺激",
  "function": "这段样本展示的承接规律，不复述剧情结论",
  "turns": [
    {"speaker": "老师", "line": "原文台词"},
    {"speaker": "角色名", "line": "原文台词"},
    {"speaker": "老师", "line": "原文台词"}
  ]
}
```

- `phase` 同时适用于 `speech.voice_examples` 与 `speech.voice_sequences`。它标记时间线、身体或身份阶段，不标记害羞、愤怒、紧张等情绪；情绪仍写入 `state` 或状态档案。
- 场景需要隔离阶段时，在场景卡使用 `"character_phase": {"角色全名": "阶段名"}`。抽取器排除明确不匹配的样本；未填写 `phase` 的旧样本和未填写 `character_phase` 的旧场景继续兼容。
- `turns` 保留 3—8 个相邻话轮；不要只截角色的名句。
- 至少一半样本应包含目标角色与老师或重要关系对象的来回承接。
- 台词只做繁简统一和明显说话人格式规整，不润色、不改写。
- 不得把不同剧情拼接成看似连续的对话，也不得把摘要改写成台词。
- `context` 不泄露片段之后的结果；`function` 描述接话方式，不写“应该怎样仿写”。
- 专有名词可以保留。来源隔离按 `source_id` 完成，不靠删除人物名、地名或道具名。

含老师话轮的新样本必须显式填写 `sample_form`：

- `bond_choice`：羁绊剧情中的玩家选项式回复，只校准接话方向与它引起的学生反应，不校准老师句长。
- `main_story_choice`：主线中的玩家选项式回复，用途同上。
- `scene_dialogue`：官方场景中的连续对白，可校准关系距离与承接；老师完整语体仍与二创文学对白样本共同决定。
- `momotalk`：聊天消息，只校准消息往返和等待节奏，不把消息长度、断句直接搬进现场对白。

未标注的旧样本仍可服务学生声音，但不得自动升级为老师语体参照；不依据短句、引号或 source_id 猜测来源形态。

## 使用边界

- 普通写作最多抽取 3 段与本场语义相关的样本。
- 开放式人味双盲必须保留至少 2 个非目标来源、且 `evidence_status` 为 `local_exact` 或 `local_variant` 的连续样本；无标签与 `external_unverified` 一律排除。不足即停止，不能假装完成有效测试。
- 剧情受控复写可在没有连续样本时退回单句例句，但必须如实记录。
- 写手只学习“上一句怎样改变下一句”，不得搬运样本中的物件、愿望、笑点和剧情路线。
- 老师仍由 `老师在场规则.md` 管理，不建立老师人物卡；官方师生话轮负责“接什么”，优秀二创连续对白负责“怎样说成完整的文学对白”。
