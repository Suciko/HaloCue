# 写作内核

## 话轮内核

1. **承接对象**：本句接上一轮的哪个词、动作、判断或潜台词？不接时，现场发生了什么让注意转移？
2. **话语动作**：追加、反驳、修正、退让、确认、试探、拖延、转移、关门，只选当前真正发生的动作。
3. **暴露量**：人物知道多少不等于此刻说多少。欲望、防备与关系决定说出、藏住或说歪的部分。
4. **对方接球**：人常只接一句话中最刺自己的部分；不要逐项理解和回应。

## 双线推进

- **外在线**：目标 → 阻碍或信息变化 → 角色选择 → 可见后果 → 新局面。
- **内在线**：隐藏期待 → 防御 → 被触动 → 靠近、后退或偏离 → 未说明的余波。它是检查方向，不是固定五拍。
- **双线交汇**：关键动作最好同时改变事情与关系；情绪若不改变选择、动作或说法，只是装饰。
- 角色不知道的事不让角色说，也不让旁白借角色口吻说给观众听。

## 口语节奏

- 连续发言按注意力成组，不按固定句数；长短、沉默和补充由状态变化产生。
- 当前状态的句长、停顿和标点优先于通用整洁；不得修掉成立的不流畅与人物声音。
- 专业判断说出口仍是完整口语：接住现场，把够用的判断和下一步连起来；不用报告标题或清单短句。
- 虚词不是配方。“所以”“不过”“其实”只在真的推论、转向或承认时出现。
- 重复可用于确认、抗拒、拖延或短路；只为显得像人就删。
- 一句只承担一个主要动作，不塞入观察、解释、安慰和结论。

## 信息取舍

- 只保留会改变注意、选择、关系、因果或现场结果的内容。
- 行政细节必须来自场景卡、角色卡或当前动作。不得为了让理由显得完整，凭空补文件原本、签章、处分记录或日程表；一个笼统事实足以推进时就停。
- 精确参数必须有现场来源。阈值、时长、编号或系统指标若不在场景卡、人物卡或已发生的计算中，不得为了显得专业而补造。
- 不把前面两处以上的经历汇总成证据清单，再推出情绪结论。
- 允许生活毛边：重复劳动可跳过，小失误、没接上的话和未解决的小事可以留下；不为完整而补齐流程。
- 人物卡标签是判断依据，不是台词任务；人物特征不是每句表演任务。只在触发时显现，普通说法承担大多数信息；未触发的口癖、术语和防御不出现。
- 特征只在刺激仍在时续存；刺激消退后回到基准，不自动粘连到下一轮。
- 同一特征在状态、口癖、标点与例句中重复出现时，只算一条证据，不提高出现频率。

## 第四面墙 / 元设定边界

- 角色不知道自己处于"章节""剧情""作品"之中。台词、内心独白与旁白均不得出现"第X章""前几章""这一话""剧情需要""作者""读者""观众"等指向作品外部或作品结构本身的词。
- 角色不得以"被写出来""这是故事""在故事里""按设定"等方式自我指认虚构性。本作设定上视已发生之事为真实经历，角色按"我活过、经历过"陈述，不按"我被这样安排"陈述。
- "周目""时间线""OC 设定""能力 = 身份 = 存在"等创作层概念仅供写作者参考，不得进入角色可说出口的词。角色若涉及轮回或身世，只说自己的体感与记忆（"以前死过一次""我以前不是人"），不说"第一周目""第二周目"这类标签。
- 采访、幕后、花絮等"演出外"场景：角色仍以"经历过那些事"的身份回答，不切换成"我是被创作出来的角色"视角。题目若问"这个故事怎么来的""你为什么接受采访"，答的是角色自己的经历与动机，不是替作者解释创作意图。
- 旁白同样受此约束：禁止"正如前文所述""回到第三章的伏笔""为后文埋下"等作者式串讲。场景内的回顾与回忆，由角色因当前刺激自然想起，不由旁白跨章点题。

## 潜台词与措辞

- 隐藏动机不是自我认识台词。它只能改变人物注意什么、避开什么、选什么；没有足够累积时，不让人物准确说出“其实我只是想……”之类作者答案。
- 压力越高，句子未必越完整。人物可能抓住一个词、改口太晚或干脆停住，不会因为接近情感核心就突然说得更有条理。
- 抽象理论标签、专业名词和漂亮概括只有角色平时会用且眼前确实需要时才出现；不要替普通借口发明理论名称。
- 角色中文名称统一采用已选人物卡中的日服常用汉译，不在同一剧本中混用国际服、国服或其他译名。同一角色的全名、简称和其他译名是检索别名，不是新的角色；制作交付时沿用已确认的 AA 显示名称。已有正文中的名称修订必须作为可审查改动提出，不能借演出生成悄悄改写原文。
- “这个、那个、这种事”必须与现场有共同指向；若读者只能靠作者猜测补出对象，就改回具体刺激。
- 动作不能替台词演情绪。摸物件、收武器、看窗外只有改变位置、物件或对方下一反应时才写，不用来给每次停顿配镜头。

## 标点与句式风险

- 破折号只用于可指出的打断者、抢话或拉长音。若改为逗号、省略号或直接换行不损失现场事件，就不用。
- 省略号表示确有停顿、迟疑或未完成，不是统一的人味滤镜。
- 否定式对照可以纠正具体事实；“不是……而是……”若在替人物解释主题、关系或成长，改成现场反应。
- 连续话轮若反复使用同一连接词、同一停顿或三项列举，说明模型在套句式。

## 收束

停止条件是边界，不是最后一句答案。事实成立后可以草率结束、被打断或留下未回答的问题；不要补主题回扣、正式承诺和漂亮镜头。

## 语体

先区分**可保留的 ACG 译文语体**、**生硬直译**与**中性编辑选择**。保留角色成立的称呼、停顿和类型对白，只修正读不通的直译与作者式说明；不把所有人物统一改成现代网络口语。
