# 已保存设定的场景影响追踪

## 使用
人物卡或世界观卡 → “修改影响预览”：显示实际选用该卡、或上次本场检查使用过该卡的场景。按场景 ID 打开后，在正文上方的“资料变更检查”查看变化字段，再明确选择“重新检查本场”。

- 展开／刷新报告不调用模型、不生成候选、不保存正文或设定。
- “重新检查本场”复用原有本场检查：使用当前写作服务，产生检查结果及 Gate，不改正文。未保存正文必须先保存。
- 卡片有未保存修改时不允许通过本入口跳走；报告不把表单草稿当成已保存设定。
- 不新增主导航。场景入口默认折叠；从影响列表定位时展开。既有完整上下文选择器不被强制展开。

## 数据依据与边界
GET `/api/v1/works/{work_id}/knowledge-impact` → `knowledge-change-impact/1.0`。`/capabilities` 声明同名能力；旧后端不请求该接口。

只读投影在一个数据库读事务中取得作品版本、正式资料和最近 scene.review Gate；校验它对应的 succeeded AgentRun、输入快照 SHA-256、scene/revision ID，然后比较当时和现在的资料。

- 人物按 runtime card 中的 `source_revision_id` 找回同作品正式卡片稳定 ID；不通过模型输出或显示名称猜目标。
- 世界观只比较被选中的实体内容，不把整个 WorldBible 的任何修订都当成所有世界卡变化。
- 显式场景选择按固定 ID；旧作品仅按既有 Brief角色＋全部已确认世界卡的兼容规则列出，并标明兼容范围，不扫描正文字符串猜引用。
- 输出字段名／标签、当前与基准修订信息、检查时间和原因，不复制整份人物资料至前端报告。
- `needs_review` 只表示资料／正文／场景契约相对检查基准有变化，不声称发现语义矛盾；`unchanged` 只表示本报告范围未变化，不等于检查无意见或通过发布。
- 新场景或没有历史检查：`not_reviewed`；最新检查缺失或损坏：`baseline_unavailable`，不悄悄回退旧检查以显示已核对。
- 未确认／已归档的显式选用资料保持不可用提示，不通过复查“洗白”。删除／撤出与新增选用分别显示。
- 证据文件、世界规则、时间线、作品事实等不在本轮字段级比较范围；既有完整场景和发布审查仍是权威门禁。
- 不重写已冻结定稿，不自动改稿，不自动把未确认资料升级。只是帮助定位与复查。

## 兼容
不增加数据表，不修改历史快照。已有 scene-review-input/1.0 可直接读取；无快照时明确提示尚未检查。新 read-only wire contract 独立版本化。报告不变更已有 Proposal/Gate 合约或采纳权限。

UI按作品ID和版本缓存读取，离开或作品变化时丢弃晚到结果；失败只显示局部重试，不清空卡片草稿。场景导航仍使用原来已存在的 writing_target 保存机制，不属于报告写入。
