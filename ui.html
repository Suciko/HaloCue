使用帮助
从剧本到 AA 工程
  1. 选择剧本——读取 .txt / .md，并建立当前剧情工作区。
  2. AI 初审——处理未映射角色、缺失自定义素材与异常指令。
  3. 生成准备——确认角色、开场背景与生成方式，然后生成审查草稿。
  4. 审查与安装——处理草稿问题，通过检查后编译、安装。
推荐剧本写法
一行一句台词，写成 角色名：台词；用 ## 场景标题 分场，背景用 @bg 背景名，音效用 @se 音效名。小说体、分镜表和混合 Markdown 也可以导入，系统会标出非标准格式并让 AI 通读全文，确认结果后再继续。
自定义素材怎么导入
在「本剧情素材」区点扫描素材目录，把背景放进 bgs、音效放进 sounds、角色放进 characters 子目录后批量登记；也可以用从本地导入单选文件，或从历史导入复制以前剧情里的素材。每一章都需要自己的登记副本。
素材工作台
右上角的「素材工作台」只整理跨章节履历：标记骨骼、背景或音效属于哪个系列，查看已复制到哪些章节。它不建立全局引用；要在本章使用，仍须出现在「本剧情素材」中。自定义 BGM 登记尚未开放。
审查草稿
  • 背景时间线按顺序显示全部 @bg；点节点可跳到对应卡片，点「更换」可改用本剧情自定义背景。
  • 选择卡片后会出现编辑、移动、删除等操作。
  • 「背景请求」卡表示这句需要的背景还没定，点「补背景：从历史项目复制」补上。
  • 「待处理 N 项」指还有问题没解决，解决完才能编译、安装。
接入自己的 AI 模型（API）
  1. 右上「设置」→「新建」一个配置。
  2. 选择供应商（OpenAI / Anthropic / 自定义兼容接口）。
  3. 填接口地址、模型名、密钥；勾选「启用视觉」以便读取场景。
  4. 「保存」→「设为当前」→ 点「测试文字」「测试图片」确认连通。
