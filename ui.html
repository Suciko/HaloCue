使用帮助
从剧本到 AA 工程
  1. 选择剧本——读取 .txt / .md，并建立当前剧情工作区。
  2. AI 初审——处理角色映射、场景演出规划和素材问题。
  3. 生成准备——确认初审结果后选择生成方式，再生成审查草稿。
  4. 审查与安装——处理草稿问题，通过检查后编译、安装。
推荐剧本写法
一行一个角色，用场景标题和自然语言提供判断依据。真实动作和位置变化写清楚，AI 才能把表情、气泡、动作、走位和效果协调起来。
## 场景一：商店街，午后
旁白: 商店街人声嘈杂，凯伊已经在服装店门口等候。
老师: 久等了。
凯伊: ……你为什么要把「普通」说得那么不普通。
旁白: 凯伊短暂地噎住，随后向老师走近一步。
凯伊: 那就更不行了！！
  • 角色名在全文中保持一致；地点、时间、光线和环境声音写进场景标题或旁白。
  • 不要为了触发演出机械堆叠省略号或感叹号。
  • 无需手工填写 Steam、jump 等 AA 名称，明确写出情绪转折和身体反应即可。
  • 生成后仍要进入审查草稿，确认 AI 安排的演出。
自定义素材怎么导入
在「本剧情自定义素材」区点扫描素材目录，把背景放进 bgs、音效放进 sounds、角色放进 characters 子目录后批量登记；也可以用从本地导入单选文件，或从历史导入复制以前剧情里的素材。每一章都需要自己的登记副本。
素材工作台
右上角的「素材工作台」整理跨章节履历，可按角色、背景、音效筛选，设置系列或章节归属并安全预览。「复制到当前剧情」依次显示正在校验、正在复制、正在登记和本章已登记；它会建立本章独立副本，不是全局引用。管理副本时，仍被草稿引用的章节会阻止删除并标出引用位置。角色详情可打开独立表情标注；失败后保留处理记录并可重试。自定义 BGM 登记尚未开放。
审查草稿
  • 背景时间线按剧情顺序显示系统生成的背景切换；点节点可跳到对应卡片，点「更换」可改用本剧情自定义背景，也可进入素材工作台查找。
  • 选择卡片后会出现编辑、移动、删除等操作。
  • 「背景请求」卡可直接使用默认黑屏、选择官方背景或从历史项目复制。
  • 素材复制后会重新读取本剧情素材并刷新初审或草稿；失败时按界面上的“重试初审”或“返回工作台”继续。
  • 「待处理 N 项」指还有问题没解决，解决完才能编译、安装。
接入自己的 AI 模型（API）
  1. 右上「设置」→「新建」一个配置。
  2. 选择供应商（OpenAI / Anthropic / 自定义兼容接口）。
  3. 填接口地址、模型名、密钥；勾选「启用视觉」以便读取场景。
  4. 「保存」→「设为当前」→ 点「测试文字」「测试图片」确认连通。
