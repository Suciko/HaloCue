# External AA performance proposal 1.0

Production owns this pending performance-edit projection. External MCP hosts can propose annotation edits and inserted directives on an exact bounded read window. They cannot accept proposals, rewrite frozen source/speakers, invoke a provider, compile or install. The author applies/rejects in the existing production review surface. Successful application keeps stable source-card identities, marks changed cards pending and invalidates build/install claims. Background/sound directives accept only already-frozen task keys; importing new resources and cast mapping retain their dedicated task editors.

Public before/after changes use card numbers; private snapshots pin stable IDs, version and connection. Exact retries keep proposal identity/status. Acceptance revalidates current frozen face choices and draft version, applies the whole batch under a draft lock, and rolls back every tracked draft file on failure. A fixed-file before-image journal recovers interrupted acceptance on startup or next read. Rejection works on stale proposals and never changes the draft. Old drafts without MCP records require no migration; records are private task-local user data. This contract is additive to the legacy AI generation audit, whose applied annotations retain their own decisions.
