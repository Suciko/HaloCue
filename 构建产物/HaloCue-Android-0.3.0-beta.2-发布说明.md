# HaloCue Android 0.3.0-beta.2

这是针对 Android 测试版关键流程的紧急修复，适用于 64 位 ARM 设备，建议使用 Android 10 及以上版本。

## 本次修复

- 修复生成检查草稿时错误读取桌面端 `llm.json`，导致 Android 报“文件不存在”并终止生成的问题。
- 修复 Android WebView 未显示网页确认框，导致“全部标记已审”等操作点击后没有反应的问题。
- 改进自定义 API 的模型读取：增加明确的读取状态和超时提示，读取成功后可自动选择首个模型。
- 保存模型配置后常驻显示“模型和 API Key 已安全保存”，并在模型名为空时阻止保存无效配置。
- 区分“APK 内置标识映射”和“手机已安装原版 AA”，避免把内置映射误解为安装检测结果。

## 安装说明

- 已安装 `0.3.0-beta.1` 的用户可直接覆盖安装，应用数据会保留。
- 不自动写入原版 AA 的受限目录。生成后请在原版 AA 中手动导入 `.aap`。
- Android 7-9 可以安装和运行，但将 `.aap` 发布到公共下载目录的流程目前需要 Android 10 及以上版本。
- 当前 APK 只包含 `arm64-v8a`，不支持 32 位或 x86 Android 设备。
