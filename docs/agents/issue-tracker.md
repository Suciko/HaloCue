# Issue tracker: GitHub

The canonical issue tracker for the unified HaloCue repository is GitHub Issues:
`https://github.com/Suciko/HaloCue/issues`.

Use `gh` from the repository clone for issue and PR operations. Cross-context
work belongs here. Issues in upstream reference repositories are for upstream
bugs only and do not replace a HaloCue issue.

Every implementation issue should identify its vertical slice, acceptance
criteria, dependencies, tests, and owning branch. Use labels from
`triage-labels.md` so work can move between maintainers and AFK agents without
renaming states.
