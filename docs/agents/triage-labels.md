# Triage labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer must evaluate scope, priority, and ownership |
| `needs-info` | Waiting for a reporter or collaborator to provide required facts |
| `ready-for-agent` | Acceptance criteria and dependencies are complete for AFK work |
| `ready-for-human` | Requires a product, license, design, or architecture decision |
| `wontfix` | Explicitly will not be actioned |

Keep these labels stable. Add product-area labels separately, for example
`area:client`, `area:contracts`, or `area:ba-editor`.
