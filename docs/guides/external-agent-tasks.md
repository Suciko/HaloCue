# 外部 Agent 接入（1.0 源码预览）

本功能让外部工具修改已保存的场景正文。HaloCue 在这个流程中不调用模型 API。
外部工具的订阅、额度和额外付费规则仍由该服务决定，HaloCue 不会把未知用量记成零。
当前支持局部正文修改，暂不包含新剧情生成或 AA 演出编排。

## 不支持 MCP 的工具

1. 保存正文，选择场景，在正文标题旁打开「外部 Agent」。处理本场已有候选后再建立任务。
2. 填写修改要求、起始段落和段落数量（最多 40 段），点击「建立任务」。
3. 「导出任务包」，交给外部 Agent。包内含冻结正文、相关已确认人物资料及结果格式；
   请先确认这些内容适合交给你选择的服务。
4. 让它按 `result_schema` 返回完整 JSON，不加 Markdown 代码围栏，不改 ID/校验值。
5. 回到同一任务，导入结果文件或粘贴 JSON。校验通过后会在原文位置显示候选，审查后采纳。

关闭任务窗口不会撤销任务。最近任务可恢复；任务过期、正文已改动或结果越界会拒绝提交。
如外部聊天无法读取 JSON 文件，可以复制包内容给它，再把返回 JSON 粘贴回来。
这需要手动交换；不承诺任意国产 Agent 都能自动调用软件。

## 支持 stdio MCP 的工具

首次在仓库根目录安装独立环境（Windows 示例）：

```powershell
python -m venv .venv-agent
.venv-agent/Scripts/python.exe -m pip install -r requirements-mcp.txt
```

建立任务后点击「MCP 连接配置」，按外部工具的配置方式添加 `mcpServers.halocue_task`。
不同工具的配置入口和结构可能不同；生成的配置是通用 stdio 示例，不是对所有工具的适配声明。
让外部 Agent 读取 `halocue_get_task`，按任务完成并调用 `halocue_submit_result`。
保持 HaloCue 开启，随后「刷新状态 → 查看候选」，在正文中审查。

配置引用本机连接文件和源码位置，勿公开连接文件或把它交给远程主机。
点击「撤销任务」立即停用当前连接；24 小时后自动失效。该连接只能读取这份任务的
段落/人物快照并提交候选，不能采纳候选、浏览其他作品或执行系统命令。

MCP 环境未安装时仍能使用任务包交换。现有发布压缩包没有包含这套源码桥接环境。
本次验收使用官方 SDK 客户端与合成资料，不涉及把用户剧情上传到第三方 Agent。
