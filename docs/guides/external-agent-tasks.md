# 外部 Agent 操作 HaloCue（1.0 源码预览）

支持本机 stdio MCP 的 Agent 可以在它自己的对话中读取和修改 HaloCue 场景。
当前支持已有正文的局部修改；新剧情生成和 AA 演出编排尚未接入。

## 配置一次，之后在 Agent 里说需求

1. 保持 HaloCue 开启，在「设置 → 模型服务 → 通过外部 Agent 操作 HaloCue」中
   选择允许访问的作品，点击「启用并生成配置」。
2. 复制配置，按外部 Agent 软件的方式添加 `mcpServers.halocue`。
3. 在 Agent 里直接说，例如：「找到《雨夜调查》的第一场，参考爱丽丝的资料，
   把开头的雨景写简洁一点，其他段落保持原样。」
4. Agent 自动找场景、读正文和资料、提交修改。点它返回的本机场景链接，
   在 HaloCue 正文原位查看前后对比并采纳。

日常修改无需建立任务、导出 JSON 或导入结果。继续说「再短一点」时，Agent
读取当前待审候选再调整；版本号、原文哈希和候选替换由 HaloCue 处理。
外部连接不能采纳候选或直接覆盖正式正文。断开连接后旧配置立即失效；
重新启用或更改授权范围会生成新连接，需更新 Agent 配置。项目备份恢复后也需重新启用。

只向 Agent 暴露四个工具：

| 工具 | 用途 | 常用输入 |
| --- | --- | --- |
| `halocue_find_scenes` | 按作品、章节或场景名称找场景 | 可选搜索词 |
| `halocue_read_scene` | 读当前正文或待审候选 | 场景 ID，可选段落范围/原文搜索词 |
| `halocue_search_materials` | 查同一作品的人物卡、世界观、事实 | 场景 ID，可选搜索词/资料类型 |
| `halocue_propose_scene_edit` | 提出原位正文修改 | 读取记录 ID、段落号和改后文字 |

工具所需 ID 从上一条读取结果取得；用户无需查找或填写。一次读取/修改最多 40 段，
需要更多正文时按 `next_start` 继续读取。只能修改该次读取到的段落；正文已变化、
候选已处理、重复段落或不正确的范围会被拒绝。完全相同的提交可重试，不重复创建候选。

## 源码运行环境

首次在仓库根目录安装独立环境（Windows 示例）：

```powershell
python -m venv .venv-agent
.venv-agent/Scripts/python.exe -m pip install -r requirements-mcp.txt
```

依赖使用官方 MCP Python SDK 的维护版 v1 (`mcp>=1.30,<2`)。
现有发布压缩包未包含这套源码桥接环境。不同 Agent 的配置入口可能不同，
通用 stdio 配置不代表已验收每款 Agent；只有远程 HTTP MCP 的客户端无法直接使用此配置。
配置引用本机连接文件和源码位置，请勿公开连接文件或交给远程主机。

模型调用和账号由外部 Agent 负责，HaloCue 的 MCP 工具不调用模型 API。
外部服务的订阅、用量和费用规则以该服务为准；未知用量显示为「未上报」。

## 不支持 MCP 时的备用方式

在已保存正文标题旁打开「任务包交换」，填写要求与段落范围，建立并导出任务。
让外部工具按包内 `result_schema` 返回 JSON，再导入文件或粘贴结果。
结果仍进入原位候选审查。关闭窗口不会撤销任务，可从最近任务恢复；
撤销、24 小时过期、正文改动或越界结果会阻止提交。

此备用任务格式与旧的单任务 MCP 桥接 API 保留兼容。新配置默认使用上面的四工具
直接操作模式，不提供单任务桥接入口。验收使用合成资料与官方 SDK 客户端，
不宣称已在未选择的第三方 Agent 软件中完成兼容性验收。
