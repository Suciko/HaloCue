# AA 剧本编译器发布就绪修复计划

1. 为表情任务“仅刷新预览”的成功终态添加前端回归测试，修正刷新判定与去重证据。
2. 为默认持久化、保留/清除密钥和无 pywin32 的 Windows 凭据访问添加测试，再实现系统凭据后端。
3. 为 OpenAI-compatible 文字、视觉、模型列表、usage 和错误处理添加 HTTP 合同测试，再移除运行时 SDK 依赖。
4. 为直接打开主机浏览器添加 UI 测试，移除来源选择和设备上传入口。
5. 为 Windows Known Folder 重定向添加测试，接入 Desktop、Documents、Downloads 系统路径。
6. 重排设置抽屉的连接状态与验证操作，补齐桌面和移动端响应式测试。
7. 运行聚焦测试、浏览器验证、完整测试和静态检查；范围复审后合并到 `main`。
8. 在合并后的 `main` 再次完整验证，清理工作树和功能分支，停止本任务服务并安排系统关机。
