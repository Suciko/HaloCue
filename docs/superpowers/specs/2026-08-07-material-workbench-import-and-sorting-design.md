# 素材工作台统一导入与时间排序设计

- 日期：2026-08-07
- 状态：待用户书面规格确认
- 选定方案：在现有全屏素材工作台内增加统一导入窗口，并补齐历史素材的时间排序与来源展示
- 范围：角色、背景、音效；BGM 继续保持未开放状态

## 1. 问题与目标

当前“本剧情自定义素材”区域已经提供本地导入、历史导入和素材目录扫描，但全屏“素材工作台”只能浏览、预览、复制和管理已有素材。用户进入工作台后无法新增素材，必须退出并回到剧情页，导入和管理被拆成了两个不连续的流程。

同时，工作台目前按系列名和名称排序。历史素材数量增加后，用户无法优先看到刚导入的素材，也无法从目录行判断素材首次进入库的时间和最近使用章节。

本轮目标是：

1. 在素材工作台内完成本地导入和历史素材复制，不再要求返回剧情页；
2. 默认按素材首次成功进入历史素材库的时间倒序排列；
3. 提供明确的排序选项、来源章节和时间信息；
4. 导入成功后刷新目录、定位并选中新素材；
5. 复用现有素材校验、登记、任务恢复和安全令牌边界，不创建第二套导入后端。

## 2. 产品边界

素材工作台仍是“跨章节自定义素材目录”，不是全局运行时素材源。新素材必须先登记到当前剧情的独立 AA 工程副本，成功后才进入跨章节历史素材库。

本轮支持：

- 本地导入角色骨骼；
- 本地导入背景图片；
- 本地导入音效；
- 从历史剧情中选择并复制角色、背景或音效；
- 扫描当前剧情的素材目录；
- 按时间或名称排序历史素材。

本轮不支持：

- 自定义 BGM 导入；
- 脱离当前剧情、直接写入一个全局素材目录；
- 批量拖放任意文件；
- 修改或伪造旧素材的导入时间；
- 自动删除重复素材或覆盖同名不同内容。

没有打开当前剧情时，工作台允许浏览和预览历史素材，但“导入素材”“复制到当前剧情”和“扫描素材目录”均不可执行，并明确提示先打开剧情。

## 3. 工作台布局与入口

工作台头部增加主操作“导入素材”，位置在“当前任务”和“返回”之前。按钮在没有当前剧情时禁用。

目录过滤区保持现有搜索框和类型分段控件，并新增排序选择器：

- 最近导入：默认，`imported_at` 降序；
- 最早导入：`imported_at` 升序；
- 名称 A-Z：按当前本地化名称升序；
- 名称 Z-A：按当前本地化名称降序。

排序只改变当前前端目录顺序，不改变数据库记录。搜索、类型筛选和排序组合生效。排序偏好保存在浏览器本地工作台偏好中，默认值始终为“最近导入”。

目录行在现有名称、类型、登记状态和类型化辅助信息之外，增加一行低强调元信息：

```text
2026-08-07 15:42 · 最近使用：第三章
```

若没有可恢复的旧记录时间，显示：

```text
导入时间未知 · 最近使用：第三章
```

未知时间在时间排序中排在所有有时间记录的素材之后，再按名称稳定排序。不能用数据库迁移时间冒充真实导入时间。

## 4. 统一导入窗口

点击“导入素材”打开模态窗口。窗口包含两个顶层模式：

- 本地导入；
- 从历史导入。

### 4.1 本地导入

使用类型分段控件选择角色、背景或音效。

角色字段：

- 角色标识；
- 显示名称；
- 骨骼目录或 `.skel` 文件；
- 使用现有角色骨骼完整性校验和冲突规则。

背景字段：

- 本地图片文件；
- 可选显示名称，未填写时使用文件名；
- 支持现有 PNG/JPG 校验范围。

音效字段：

- 本地音频文件；
- 可选显示名称，未填写时使用文件名；
- 支持现有 WAV/MP3/OGG 校验范围。

窗口提供“扫描当前剧情素材目录”次操作，复用现有批量扫描接口。扫描完成后窗口不立即关闭，而是显示登记、跳过和失败数量，允许用户查看结果后关闭。

### 4.2 从历史导入

复用现有历史项目与历史素材接口，但在统一窗口内呈现，不再打开与工作台重叠的第二层全屏抽屉。视图包含：

- 历史项目列表；
- 当前项目内、按所选类型过滤的素材列表；
- 搜索框；
- 默认按历史素材可用时间倒序；
- “复制到当前剧情”操作；
- 源素材缺失时的“从本地替换”恢复入口。

历史接口没有可靠时间时，使用与工作台一致的“时间未知”规则，不伪造日期。

### 4.3 状态与关闭

导入任务沿用现有状态：

```text
正在校验 -> 正在复制 -> 正在登记 -> 可用
```

失败必须保留可执行的下一步，例如重新选择文件、关闭 AA 后重试、刷新历史项目或修改冲突名称。窗口关闭后任务继续显示在工作台“当前任务”区域，并能沿用现有恢复机制。

导入成功时：

1. 刷新当前剧情素材条；
2. 刷新跨章节素材工作台接口；
3. 保持用户当前排序，不擅自切换排序方式；
4. 在当前排序结果中滚动并选中新素材；
5. 在详情区显示预览和“本章已登记”；
6. 不自动退出素材工作台。

## 5. 时间数据模型

`asset_install` 增加 `registered_at TEXT NOT NULL DEFAULT ''` 列。新素材从非登记状态首次成功变为 `registered` 时，由服务端写入 UTC ISO 8601 时间；同一 `kind + aa_key + scope` 后续重新校验或更新时保留原值。迁移前已有的记录保持空值，不写入伪造时间。

工作台聚合层把同一内容标识 `kind + aa_key + sha256` 的所有副本时间汇总：最早的非空 `registered_at` 输出为素材 `imported_at`，代表该内容首次成为可复用自定义素材的时间；最新的非空 `registered_at` 输出为 `last_used_at`。

规则如下：

- 同一内容复制到其他章节时新增该章节自己的 `registered_at`，聚合后的 `imported_at` 仍保留最早值；
- 同一章节重新校验或更新标签时不得改变该时间；
- 同名但内容摘要不同的素材是不同历史素材，各自拥有时间；
- 工作台聚合多章节副本时取所有可靠时间中的最早值作为 `imported_at`；
- 每个副本额外返回 `registered_at`，工作台取最新副本作为 `last_used_at` 和 `last_used_chapter`；
- API 只返回时间、章节显示名和不透明令牌，不返回源路径、安装路径或作用域。

新登记记录由服务端写入时间，浏览器提交的时间字段一律忽略。

旧数据若没有可靠时间：

- 不以数据库迁移时间回填；
- 不以文件修改时间冒充首次导入时间；
- API 返回空 `imported_at`；
- 前端显示“导入时间未知”，并按稳定规则排在有时间记录之后。

## 6. 接口变化

`GET /api/assets/library?story_token=...` 的每个聚合素材新增：

```json
{
  "imported_at": "2026-08-07T07:42:00Z",
  "last_used_at": "2026-08-07T08:10:00Z",
  "last_used_chapter": "第三章",
  "copies": [
    {
      "chapter": "第三章",
      "registered_at": "2026-08-07T08:10:00Z",
      "is_current": true,
      "copy_token": "opaque-token"
    }
  ]
}
```

时间未知时返回空字符串，不省略字段，便于前端稳定排序。

本地导入继续复用：

- `/api/picker`；
- `/api/assets/validate`；
- `/api/assets/register`；
- `/api/story/assets/scan-inbox`。

历史导入继续复用：

- `/api/history/projects`；
- `/api/history/assets`；
- `/api/story/assets/copy`。

不新增接受服务器绝对路径的浏览器接口，也不把路径写入浏览器会话状态。

## 7. 前端模块边界

新增 `js/library_import.js`，职责包括：

- 统一导入窗口的打开、关闭和焦点恢复；
- 本地/历史模式切换；
- 类型选择和字段校验；
- 调用现有 `StoryAssets` 导入与扫描能力；
- 监听完成事件并要求工作台刷新、定位。

`js/library.js` 继续只负责工作台路由、列表、筛选、排序和选择状态。历史素材请求逻辑可从现有 `history.js` 提取可复用控制器；剧情页原有历史抽屉保持兼容，但不得复制一份新的请求与错误映射实现。

`js/assets.js` 继续拥有当前剧情导入任务和状态机。工作台导入窗口调用公开方法，不直接复制校验、登记和任务恢复逻辑。

## 8. 响应式与可访问性

- 桌面端导入窗口宽度受控，不遮蔽关闭操作；
- `680px` 以下改为接近全屏的单列窗口；
- 类型分段、模式切换和排序选择器均保持横向文字，不出现逐字竖排；
- 最长文件名、章节名和错误信息可换行，不造成页面级横向滚动；
- 模态窗口具有 `role="dialog"`、`aria-modal="true"`、标题关联和状态播报；
- 打开后焦点进入首个可操作控件，关闭后回到“导入素材”按钮；
- `Escape` 只关闭最上层导入窗口，不关闭其后的素材工作台；
- 导入中禁止重复提交，但允许关闭窗口后在“当前任务”查看进度。

## 9. 错误处理

- 未打开剧情：禁用导入并提示先打开剧情文件；
- 文件无效：在字段旁显示现有稳定中文错误，不创建任务残留；
- 同名不同内容：停止登记，要求改名或重新选择，不覆盖；
- AA 正在运行：任务进入可重试状态，提示关闭 AA；
- 历史源缺失：允许关闭历史模式后转入本地替换；
- 工作台刷新失败但登记成功：保留“已登记，列表刷新失败”状态，并提供刷新工作台操作；
- 剧情在导入期间切换：旧任务不得写入新剧情，状态转为已中断；
- 时间字段无效：服务端输出空时间，前端按未知时间处理，不允许无效日期破坏排序。

## 10. 测试与验收

后端测试：

- 新本地导入和历史复制均写入服务端时间；
- 同一内容复制到新章节不改变最早导入时间；
- 聚合接口返回 `imported_at`、`last_used_at`、`last_used_chapter` 和副本时间；
- 旧记录没有时间时返回空值；
- API 响应不泄露路径；
- 无效或客户端伪造时间不会进入目录。

前端单元测试：

- 默认排序为最近导入；
- 最近/最早/名称正序/名称倒序均稳定；
- 未知时间排在已知时间之后；
- 搜索、类型筛选和排序组合正确；
- 导入成功后刷新并选中新素材；
- 没有当前剧情时导入入口禁用；
- 本地与历史模式不会重复绑定事件；
- 关闭窗口恢复焦点，`Escape` 不关闭工作台。

真实浏览器测试：

- `1200px`、`680px`、`470px`、`390px` 下工作台和导入窗口无横向溢出；
- 角色、背景和音效本地导入入口均可到达；
- 历史项目列表可搜索并复制；
- 时间、来源章节和排序控件在窄屏仍可读；
- 导入完成后新素材出现在最近导入列表顶部并自动选中；
- 全流程无浏览器控制台错误。

## 11. 实施顺序

1. 为素材登记补充可靠的服务端时间，并扩展工作台聚合接口；
2. 为时间聚合、旧数据兼容和路径安全增加后端测试；
3. 在工作台目录加入排序状态、时间/最近章节展示和前端测试；
4. 新增统一导入窗口并复用 `StoryAssets` 状态机；
5. 把历史选择器接入统一窗口，同时保持剧情页旧入口兼容；
6. 完成导入后刷新、定位和任务恢复；
7. 完成响应式、键盘和真实浏览器回归验证。
