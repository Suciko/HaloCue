# HaloCue 品牌名与版本方案

- 日期：2026-08-07
- 状态：已确认，待实施
- 产品正式名称：`HaloCue`
- 首个公开测试版本：`0.9.0-beta.1`

## 1. 产品定位

HaloCue 是面向 AzureArchive 创作者的剧情演出工具。它读取用户已经写好的剧情文本，核对角色与素材，安排表情、动作、站位、镜头、背景与声音，提供人工审查，并最终编译、安装为 AzureArchive 工程。

产品不以“自动写剧本”为定位。AI 负责提出演出安排，不改写原台词；用户保留审查和修改权。

## 2. 品牌写法

主品牌固定写作：

> HaloCue

大小写不得写成 `Halocue`、`HALOCUE` 或 `Halo Cue`。`Halo` 对应蔚蓝档案创作语境中的光环意象，`Cue` 使用舞台行业中“演出提示”的本义，覆盖角色、镜头、动作、灯光、声音等演出信息。

公开中文副标题固定为：

> AzureArchive 剧情演出工具

英文副标题固定为：

> Narrative Staging for AzureArchive

首次面向不熟悉产品的用户展示时，使用“品牌名 + 副标题”。应用内空间有限或上下文已经明确时，只显示 `HaloCue`。

## 3. 版本方案

首个公开测试版本采用 Semantic Versioning 预发布格式：

> `0.9.0-beta.1`

面向普通用户的界面与宣传文案显示：

> HaloCue 0.9 Beta

文件名、诊断信息和程序元数据使用完整版本号，例如：

> `HaloCue-0.9.0-beta.1-windows.zip`

后续测试修复依次发布 `0.9.0-beta.2`、`0.9.0-beta.3`。新增但保持兼容的测试功能可升为 `0.9.1-beta.1`。当安装、生成、审查和升级流程经过公开测试并达到稳定发布标准后，发布 `1.0.0`。

设计文档中的 `v1.3` 等编号仅表示文档修订版本，不得作为产品版本展示。

## 4. 旧称迁移

现有“AA 自动写剧本”和“AA 剧本编译器”统一视为历史工作名。实施时按以下顺序替换用户可见名称：

1. 应用标题、启动器标题与欢迎界面。
2. 使用说明、README 与发布文案。
3. 发布包、启动脚本和诊断报告中的显示名称。

首个测试版可以在说明文档中保留一次过渡表述：“HaloCue，原 AA 剧本编译器”。程序目录、Python 模块名和已有数据目录不因品牌更名而强制迁移，避免破坏用户环境与历史数据。

## 5. 命名边界

- 主品牌不附加 `AI`、`Studio`、`Forge`、`Pilot` 或 `Compiler`。
- 不把 `AzureArchive` 或《蔚蓝档案》并入主品牌，以保持第三方工具身份。
- 不宣称官方授权或隶属关系。
- 发布前仍需进行正式的商标、域名及主要软件分发平台重名核查；当前网页与 GitHub 搜索只构成初步排重。

## 6. 验收标准

- 所有主要用户入口一致显示 `HaloCue`。
- 首个测试版在用户界面显示 `HaloCue 0.9 Beta`。
- 诊断和发布产物可查到完整版本 `0.9.0-beta.1`。
- 用户文档准确说明产品不会改写原台词。
- 保留原有文件与数据路径兼容性。
