# AA 剧本编译器：素材工作台复用、预览与副本管理设计

- 日期：2026-08-02
- 状态：交互方案已确认，等待用户审阅书面规格
- 已选方案：B，独立全屏工作区
- 范围：自定义素材工作台、复制到当前剧情、预览、章节副本管理、与 AI 初审及草稿审查的联动
- 版本管理：已在 `01-完整程序/aa` 建立本地 Git 仓库；实施前仍按项目约束另建文件备份

## 1. 决策摘要

完整的素材工作台不再使用右侧抽屉，而是在现有单页 Web UI 内作为独立全屏工作区出现。它不是新浏览器窗口，也不是脱离当前剧情的全局文件管理器。

工作台负责：

1. 浏览全部历史剧情中已经登记的用户自定义素材；
2. 通过安全预览确认素材内容；
3. 标记素材属于系列共用还是章节专用；
4. 把素材复制并独立登记到当前剧情的 AA 工程；
5. 查看素材已经存在于哪些章节，并按章节移除副本；
6. 从 AI 初审接收缺失素材任务，完成后返回原流程并刷新问题状态；
7. 为自定义骨骼角色进入独立的表情标注工作区。

工作台中的历史素材不是运行时全局引用。AA 每个剧情工程仍必须拥有自己的素材副本和登记记录。

## 2. 设计依据

本设计吸收下列成熟产品的通用模式，但按 AA 的工程隔离规则调整：

- Adobe Creative Cloud Libraries：素材先被组织、识别和预览，再用于具体作品；
- Unity 本地素材包：选择内容后导入当前工程，项目获得自己的素材；
- Unreal Migrate：复制素材及依赖到目标工程，并显示迁移进度、冲突与结果；
- Figma Assets：目录负责查找，详情负责确认，插入当前文档是明确主操作。

AA 与 Figma 的关键区别是不能保持跨工程链接。因此，工作台的主操作必须写成“复制到当前剧情”，不能写成含义模糊的“使用”“添加”或“引用”。

## 3. 产品边界

### 3.1 工作台是什么

工作台是当前 Web 应用中的全屏工具视图。进入时保留当前剧情身份、发起位置和待解决任务；退出时返回原步骤。

它同时提供三类视图：

- `系列素材库`：跨章节查找、预览和归类；
- `当前剧情素材`：只显示当前剧情已经复制登记的自定义素材；
- `副本记录`：查看同一素材存在于哪些章节并管理副本。

### 3.2 工作台不是什么

本轮不做：

- 直接让当前剧情引用历史工程目录；
- 展示数据库中 `observed`、`verified` 等内置素材；
- 任意文件浏览器或物理路径管理器；
- 在卡片上直接提供“删除所有章节副本”；
- 把骨骼表情标注塞进主剧情生成链路；
- 在 BGM 原生登记契约未验证前，把 BGM 显示为可复制素材。

## 4. 进入和返回

### 4.1 入口

工作台有三类入口：

1. 顶部“素材工作台”：普通浏览模式；
2. AI 初审问题：“去补素材”：带一个或多个缺失素材任务进入；
3. 草稿审查中的背景请求、背景时间线或素材选择：“更换/从历史导入”：带具体卡片和素材类型进入。

### 4.2 导航上下文

进入时前端保存一个只存在于浏览器状态中的返回上下文：

```json
{
  "origin": "preflight | review | story_assets | topbar",
  "story_token": "不透明剧情令牌",
  "draft_id": "可选",
  "card_id": "可选",
  "asset_kind": "可选",
  "request_id": "可选"
}
```

浏览器不得接收源剧本绝对路径、AA 数据目录、素材源路径或安装路径。

### 4.3 返回行为

- 普通浏览模式返回进入前的页面滚动位置；
- AI 初审模式返回后重新读取初审结果和当前剧情素材，并刷新缺失项；
- 草稿审查模式返回后重新读取草稿 revision；若素材复制成功且发起操作要求应用素材，则继续执行带版本控制的草稿更新；
- 当前剧情在工作台打开期间发生变化时，中止应用操作并明确提示，不得把素材写入新剧情；
- 浏览器刷新后可以恢复当前剧情，但不自动重放尚未确认的草稿应用操作。

## 5. 页面布局

### 5.1 桌面宽屏

宽度充足时采用三段结构：

```text
┌ 素材目录 330–360px ┬ 素材详情 minmax(360px, 1fr) ┬ 当前剧情任务 280–300px ┐
│ 搜索结果与状态      │ 大图/骨骼/音频预览          │ AI 初审缺失项          │
│ 点击选择素材        │ 章节履历与主操作             │ 复制并解决问题          │
└────────────────────┴─────────────────────────────┴───────────────────────┘
```

- 工作区总宽度不足约 `900px` 时收起右侧任务面板；
- 不足约 `680px` 时只显示素材目录；点击素材进入详情层或底部抽屉；
- 响应式判断以工作台容器宽度为准，不能只依赖浏览器 viewport；
- 任何宽度都不得出现页面级横向滚动。

### 5.2 目录信息层级

每一行固定包含：

1. 类型化预览；
2. 素材名称，第一视觉层，允许最多两行；
3. 明文类型：`骨骼`、`背景`、`音效`；
4. 当前剧情状态：`本章已登记`、`未登记`、`复制中`、`需核对`；
5. 一条随类型变化的低强调辅助信息。

辅助信息规则：

| 类型 | 预览 | 辅助信息 |
|---|---|---|
| 骨骼角色 | 头像；无头像时用明确占位 | 文件完整度、表情数量或标注状态 |
| 背景 | 16:9 缩略图 | 分辨率、时间/地点等场景标签 |
| 音效 | 播放图标、时长 | 时长、听感或格式摘要 |

不能只用颜色区分素材类型和状态。名称必须显著大于类型、技术信息和状态标签。

### 5.3 顶部过滤

- 搜索框支持素材名、系列名、章节名和安全的 AI 标签；
- 类型使用分段按钮：全部、骨骼、背景、音效；
- 可追加“系列共用/章节专用”“本章已登记/未登记”过滤；
- 窄屏时搜索框独占一行，类型按钮保持横排且允许等宽缩放；
- 不把搜索框和多个按钮压缩成竖排文字。

### 5.4 详情区

详情区提供：

- 大图、头像/骨骼联系表或原位音频试听；
- 名称、类型、系列归属和安全元数据；
- 已登记章节列表；
- 当前剧情是否已经登记；
- 主操作“复制到当前剧情”或不可点击状态“本章已登记”；
- 次操作“管理副本”；
- 骨骼角色的“表情标注”。

“保存分类”不再占据每张目录卡的固定空间。分类编辑放在详情区，变更后立即显示保存中、成功或失败。

## 6. 当前剧情任务面板

AI 初审和草稿审查可以向工作台传入结构化任务：

```json
{
  "task_id": "前端或服务端任务标识",
  "kind": "background | sound | character",
  "requested_name": "雨夜天台",
  "source_location": {"line": 46, "card_id": "可选"},
  "reason": "剧本引用但当前剧情未登记",
  "candidate_keys": ["可选的素材候选"]
}
```

任务面板显示：

- 缺少什么；
- 在剧本或草稿中的位置；
- 为什么需要处理；
- 已找到多少候选；
- “复制并解决问题”或“查看候选”。

任务解决后原位转为完成状态。全部任务解决不强制自动退出，用户可以选择“返回 AI 初审/返回草稿审查”。

## 7. 自定义素材判定

所有工作台、当前剧情素材带、审查素材面板和初审素材候选统一采用同一判定函数。

自定义素材必须同时满足：

1. `asset_install.status = 'registered'`；
2. 来源属于 `overrides`、`custom`、本地导入或历史复制登记；
3. 不是数据库内置的 `observed`、`verified`、`builtin`、`database`、`library` 等来源；
4. 当前剧情素材视图还必须匹配当前剧情作用域。

系列素材库按 `kind + aa_key + sha256` 聚合同一内容的多个章节副本，但返回值不得包含 `source_path`、`install_path` 或 `scope`。章节只返回安全显示名和不透明副本标识。

## 8. 安全预览

### 8.1 预览标识

系列素材库接口为每个可预览素材返回不透明 `preview_token` 或等价安全标识，不能要求浏览器提交服务器路径。

预览令牌绑定：

- 素材类型；
- `aa_key`；
- 内容摘要 `sha256`；
- 一个已经验证为用户自定义素材的登记副本；
- 短有效期或服务进程级签名。

### 8.2 类型行为

- 背景返回受控缩略图或原图流；
- 角色只从登记目录内的头像/受控渲染产物读取；
- 音频支持已有的单段 Range 播放；
- 预览文件缺失时卡片仍可管理，但显示“预览不可用”；
- BGM 在登记契约开放前不进入工作台列表。

服务端必须再次校验解析后的真实文件仍位于该登记副本允许的目录内。

## 9. 复制到当前剧情

### 9.1 请求

统一事务接口接受：

```json
{
  "story_token": "当前剧情不透明令牌",
  "kind": "background | sound | character",
  "aa_key": "素材键",
  "sha256": "内容摘要",
  "source_copy_token": "历史副本不透明令牌"
}
```

浏览器不提交目标路径、源路径或 AA 数据目录。

### 9.2 后端流程

```text
校验 story_token 并解析不可变目标作用域
→ 校验源副本仍是 registered 自定义素材
→ 校验源文件存在且位于登记路径内
→ 检查当前剧情是否已有同内容登记
→ 验证类型、文件完整性和同名冲突
→ 复制到当前剧情 project/save 所需位置
→ 原子更新 AA 登记/manifest
→ 写入当前剧情 asset_catalog，记录 history_import 来源
→ 返回当前剧情安全素材卡
```

角色骨骼作为一组文件复制，不能只复制头像或单个 `.skel` 文件。背景和音效复用现有验证规则。

### 9.3 幂等与冲突

- 同一内容已经登记：返回 `already_registered`，不重复复制；
- 同键同内容：完成幂等登记；
- 同键不同内容：停止并要求用户选择重命名/新键，不能静默覆盖；
- 源副本已经丢失：显示具体章节和“源文件缺失”，不创建空记录；
- 中途失败：文件和登记记录成对回滚；
- AA 必须关闭时：任务暂停在“等待关闭 AA”，用户原位重试。

### 9.4 前端反馈

目录行和任务面板同时显示稳定状态：

```text
正在校验
→ 正在复制
→ 正在登记
→ 本章已登记
```

失败信息必须给出下一步，如“源章节副本已丢失，请改选其他副本”“当前剧情存在同名不同内容，请重命名后导入”。不得只显示异常类名或原始堆栈。

## 10. 草稿应用

“复制到当前剧情”和“把素材应用到草稿卡片”是两个连续但独立的事务。

1. 先完成素材复制登记；
2. 再使用最新 `draft_revision` 更新具体卡片；
3. 背景时间线更换时保持原 `card_id` 不变，只更新对应 `@bg` 卡的参数；
4. `background_request` 可复用现有 `resolve_background_request` 的锁和版本模式；
5. 草稿版本冲突时素材仍留在当前剧情，刷新草稿后让用户再次确认应用，不能回滚已经成功的素材登记。

## 11. 副本管理和删除

### 11.1 默认语义

“删除”不能作为素材卡片的常驻主操作。默认安全操作是：

- 在当前剧情视图中：`从当前剧情移除副本`；
- 在副本记录中：选择一个具体章节，`移除该章节副本`。

其他章节副本和素材分类资料保留。

### 11.2 删除前检查

服务端删除前检查：

- 目标副本确实属于指定剧情作用域；
- 是否被该剧情任一草稿引用；
- 是否存在运行中的编译/安装或素材任务；
- project/save 镜像和 manifest 是否一致；
- 请求使用的副本令牌仍有效。

如果被草稿引用，默认阻止删除，并列出安全的草稿显示名、引用数量和可跳转位置。第一版不做“自动替换全部引用后删除”。

### 11.3 确认界面

确认文案必须包含素材名和目标章节：

```text
从“凯伊约会篇 · 第二章”移除“雨夜天台”？
这只移除该章节的独立副本，不影响第一章和第三章。
```

按钮使用“移除该章节副本”，不能只写“确定”。

“删除所有章节副本”属于未来的危险批量管理能力。本轮不实现，以避免跨工程误删和引用链复杂化。

### 11.4 删除事务

```text
解析故事与副本令牌
→ 引用和任务检查
→ 备份待修改 manifest
→ 从 project/save 登记移除
→ 删除该作用域内的物理副本
→ 删除 asset_catalog 的该作用域记录
→ 重新聚合系列素材库
```

失败时恢复 manifest 和文件。不得先删除文件再验证引用或作用域。

## 12. 骨骼表情标注

骨骼表情标注继续作为独立的大型工作区，不混入“剧本 → AI 初审 → 生成 → 审查”的主链路。

素材工作台中的角色详情提供入口，并显示：

- 骨骼文件完整度；
- 头像和联系表；
- 已渲染候选数量；
- AI 语义标注状态；
- 最近一次任务进度和错误；
- “开始/重新标注”。

标注完成只更新素材元数据和语义候选，不自动改写任何草稿。AI 初审和正式生成只能读取已保存的表情能力白名单。

## 13. 与现有界面的分工

### 13.1 本剧情素材带

保留在主流程中，只显示当前剧情已登记的自定义素材摘要和最近任务，不承担跨章节管理。

提供：

- 当前剧情素材数量；
- 小型类型过滤；
- 快速预览；
- “打开素材工作台”；
- 本地导入和历史复制任务状态。

### 13.2 历史素材抽屉

保留为就地快速选择器，只用于“我正在替换这一张背景/音效”的短流程：

- 过滤到指定素材类型；
- 选择一个历史素材；
- 复制到当前剧情；
- 返回发起卡片。

需要分类、比较预览、表情标注或管理副本时，转入全屏工作台。

### 13.3 审查素材面板

继续只展示当前剧情已登记自定义素材。点击素材可预览；点击“更换”进入快速选择器或工作台任务模式。

## 14. 后端接口建议

沿用现有接口命名风格，建议新增或扩展：

- `GET /api/assets/library?story_token=...`：返回系列聚合和当前剧情登记状态；
- `GET /api/assets/library/preview?preview_token=...`：安全预览；
- `POST /api/assets/library/copy-to-story`：复制并登记；
- `GET /api/assets/library/copies`：返回安全的章节副本列表；
- `POST /api/assets/library/remove-copy`：移除指定章节副本；
- `POST /api/assets/library/profile`：保留系列/章节分类；
- 现有表情标注任务接口继续复用，但入口移入角色详情。

所有变更接口返回结构化错误码和中文可执行信息。对文件系统的写入必须使用服务端解析的剧情/副本令牌，不能信任浏览器路径。

## 15. 前端模块边界

避免继续膨胀单个 `library.js`，实施时拆分职责：

- `library.js`：工作台路由、进入/退出、过滤和选中状态；
- `library_preview.js`：类型化预览与音频播放；
- `library_transfer.js`：复制任务、进度和冲突处理；
- `library_copies.js`：副本列表、引用检查结果和移除确认；
- `library_faces.js` 或现有独立模块：骨骼表情标注工作区；
- `story.js`：只提供当前剧情上下文和刷新通知；
- `assets.js`：主流程的本剧情素材带，不获取全局历史库。

仍严格遵守 CSP：不使用内联脚本、内联事件、`eval` 或 `innerHTML` 拼接不可信数据；事件通过 `addEventListener`，文本通过 `textContent`。

## 16. 测试和验收

### 16.1 数据和安全

- 只聚合 `registered` 用户自定义素材；
- 内置 `observed/verified` 素材不进入任一自定义素材展示面；
- API JSON 不含服务器绝对路径；
- 篡改、过期或跨类型预览/副本令牌被拒绝；
- 预览解析后仍执行目录边界检查；
- 当前剧情切换后，旧任务不能写入新剧情。

### 16.2 复制

- 背景、音效和完整角色骨骼可以复制到当前剧情；
- 同内容重复请求幂等；
- 同名不同内容不会覆盖；
- 源文件缺失不会留下登记；
- project/save/manifest 任一步失败均回滚；
- 成功后 `/api/story/assets`、AI 初审和审查素材面板立即可见。

### 16.3 删除

- 默认只移除选定章节副本；
- 其他章节副本和系列分类保留；
- 有草稿引用时阻止删除并返回引用位置；
- 删除事务失败可恢复；
- 界面中不存在卡片级“删除所有副本”快捷操作。

### 16.4 前端交互

- 桌面宽屏显示目录、详情和任务三栏；

## 17. 实施顺序

1. 建立安全预览令牌和系列库当前剧情状态；
