# AA 剧本编译器发布就绪修复设计

## 目标

修复表情工作台与模型配置中影响正常发布的断点，使首次使用者无需理解临时密钥、Python SDK 或主机/设备来源差异即可完成配置和选取文件。

## 行为设计

### 表情预览刷新

表情任务进入成功终态后，只要结果包含渲染、预览刷新或标注写入，当前工作台就强制重新读取数据库记录。预览 URL 使用记录版本作为缓存键，因此新图片会在当前侧栏中立即替换。现有 generation、角色标识与哈希校验继续阻止过期响应污染当前角色。

### 模型密钥

非空 API Key 保存时直接写入 Windows Credential Manager；留空表示保留既有密钥；“清除密钥”是单独的显式操作。界面展示“已安全保存”或“未配置”，不再让用户选择临时保存方式。

Windows 凭据访问使用标准库 `ctypes` 调用系统 API，并在已安装 pywin32 时保持兼容。OpenAI-compatible 调用使用标准库 HTTP 客户端访问 `/chat/completions` 与 `/models`，支持文字、JSON schema、多模态 data URL、usage 统计和可读错误，不要求安装 `openai` 包。

### 剧本文件选择

“选择文件”直接打开运行 AA 的主机文件浏览器。设备上传接口保留兼容性，但桌面 UI 不再展示来源选择页和返回来源按钮。目录/文件路径设置继续复用主机浏览器。

### Windows 特殊目录

在 Windows 上通过 `SHGetKnownFolderPath` 解析 Desktop、Documents 和 Downloads 的实际重定向位置。系统调用失败或非 Windows 环境回退到用户目录下的传统路径；测试注入 `home` 时也保持确定性回退。

## 发布验收

- 无 API Key 时状态明确；保存后重启服务仍可解析密钥；清除动作可撤销配置。
- OpenAI-compatible 文字、视觉和模型列表不依赖第三方 SDK。
- 表情任务只刷新图片也会在当前侧栏立即更新。
- 剧本选择器首次打开即显示主机目录，桌面入口指向系统真实桌面。
- 桌面、平板和手机视口无横向溢出、页面级双滚动或控件越界。
- 不改动任何特定骨骼或表情编号的几何数据。
