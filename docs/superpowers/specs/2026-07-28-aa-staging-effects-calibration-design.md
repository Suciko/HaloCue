# AA 动作、站位与效果校准设计

## 目标

建立一个隔离的 AA 校准工程，以实际预览确认动作 1–7、人物效果位标记、位置
与入退场的视觉含义；同时固化背景效果的生命周期规则。校准结果将成为模型和
生成器以后唯一可使用的演出语义。

## 已确认事实

- 动作编号为：1 向下确认、2 向左倒、3 向右倒、4/5 两种颤抖、6 跳一次、7 连跳两次。
- `shapeOverride` 是可叠加位标记：1 通讯、2 黑屏剪影、4 特写；本地历史工程已
  实际出现 5（通讯+特写）与 6（黑屏剪影+特写）。
- 位置使用 1–5；`startingPos` 与 `endingPos` 不同即为走位。
- `appear` 为 1 左入、2 右入、3 普通登场、4 左退、5 右退、6 普通退场。
- 集中线、闪白、传送等短暂背景效果应在下一句写 `bgEffect=0`；雨、雪、雾等
  环境效果持续到显式写 `bgEffect=0`。

## 隔离测试工程

工程名固定为 `AA_演出语义校准_20260728`，只使用已登记的凯伊约会服骨骼
`626652156`。工程包含以下独立段落，所有段落均带可读的台词标签：

1. 动作 1–7，每个动作单独一行，角色固定在位置 3。
2. 角色效果：通讯(1)、黑屏剪影(2)、特写(4)、通讯+特写(5)、黑屏剪影+特写(6)、
   三者同时(7)，每种效果后一行写 0 复位。
3. 站位和移动：依次展示位置 1、2、3、4、5，再展示 1→3、3→5、5→2 走位。
4. 入退场：左入、右入、普通登场、左退、右退、普通退场各一次。
5. 背景效果：集中线一行，紧随 `无`；雨连续两行，随后 `无`；雪连续两行，随后
   `无`；雾连续两行，随后 `无`。

## 后续生成规则

校准预览由用户确认后，工具将采用以下规则：

- 模型只输出动作名称和效果名称，不输出数字；转换器使用受限映射解析。
- 人物效果在输入层表示为可组合列表，转换器将位值求和；下一条该角色记录默认
  复位为 0，除非同一行重新声明效果。
- 特写只能在角色已经在台上时使用；它表示摄像机距离变化，不替代站位或走位。
- 短暂背景效果自动在下一对白复位；环境背景效果保持，直到模型或剧本明确写“无”。
- 走位、入场、退场和效果应按剧情动作触发，不能把每句台词都加演出。

## 验证

生成前要求 AA 关闭。生成后运行结构与资源闭包校验；用户在 AA 中预览并确认
动作 4/5 的视觉对应、三效果组合、位置、入退场与背景效果复位。未经用户实际
确认的数值不会进入自动标注提示词。
