# 演绎提示词表情变化规则设计

## 目标

调整 AI 演绎提示词，使所有有立绘角色在每次开口时都优先选择一个不同且语义合适的已登记表情。对于可用表情较少的角色，同样主动尝试变化；只有确实找不到符合当前台词、语气和情绪阶段的其他表情时，才保持上一表情。

## 方案比较

1. **积极变化、语义优先（采用）**：默认寻找不同的合适表情，把保持原表情作为兜底。符合“尽量每句变化”，同时避免明显错情绪。
2. **每句强制变化（不采用）**：能最大化变化率，但会迫使表情较少的角色使用不合语境的差分。
3. **仅对少表情角色设特殊规则（不采用）**：需要人为定义数量阈值，且不能改善其他角色的连续复用问题。

## 规则调整

- 把“必须有明确情绪变化才换”改为“每次开口先寻找不同且合适的候选”。
- 即使相邻台词处于相近情绪，只要另一个表情同样贴切，也优先变化。
- 只有同一句拆分的连续气口，或其他候选都不合适时，才保持原表情。
- 保留表情白名单、逐编号语义优先、禁止猜测裸编号等现有安全约束。
- 明确禁止为了变化而机械轮换或使用明显不合语境的表情。

## 验证

在提示词契约测试中断言“优先选择不同表情”和“没有合适候选才保持”两项规则存在，并移除旧的保守连续性断言。运行相关提示词测试，确认生成规则文本和资源安全约束不受影响。
