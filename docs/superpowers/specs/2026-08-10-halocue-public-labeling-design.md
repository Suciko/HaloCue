# HaloCue 公开展示名调整设计

- 日期：2026-08-10
- 状态：待用户复核
- 主品牌：`HaloCue`
- 当前中文定位：`AA 剧本自动演出工具`

## 1. 目标

保留已经发布的 `HaloCue` 品牌，同时让中文 AzureArchive 用户第一眼理解产品用途。此次只调整公开展示文案，不重命名仓库、程序包、包名、数据目录或导出目录。

## 2. GitHub 展示

- 仓库名继续使用 `Suciko/HaloCue`。
- README 主标题改为 `HaloCue｜AA 剧本自动演出工具`。
- README 开头明确说明：现版本读取用户已经写好的剧本，自动安排表情、动作、站位、镜头、背景和声音，经过人工审查后编译为 AzureArchive 工程；现版本不以 AI 自动写剧本为功能承诺。
- GitHub About 描述改为中英可检索的简短说明，包含 `HaloCue`、`AzureArchive`、`AA 剧本自动演出工具` 和 `narrative staging`。
- 为仓库增加与实际功能相符的 Topics；不加入尚未公开实现的 AI 剧本创作能力。
- 已发布版本的展示标题改为 `HaloCue 0.9 Beta｜AA 剧本自动演出工具`，标签 `v0.9.0-beta.1`、附件文件名和版本号保持不变。

## 3. 安卓端展示

- Android 启动器图标下方继续显示 `HaloCue`，避免长中文名称被桌面截断。
- 应用首屏使用 `HaloCue` 作为主标题，并显示 `AA 剧本自动演出工具` 作为副标题。
- APK 文件名和对外发布标题可以带上 `Android` 与中文定位，但应用 ID `com.halocue.android` 不变。
- `Download/HaloCue/`、应用数据路径、设置键和已有用户数据均不迁移。
- 在完整电脑端功能尚未迁移前，安卓页面仍要明确说明当前只能生成、导出和分享 `.aap`，不能声称功能已与 Windows 版完全一致，也不能声称已自动导入原版 AA。

## 4. 未来演进

AI 剧本创作成为已公开、可用且经过验证的功能后，中文副标题可以从 `AA 剧本自动演出工具` 调整为 `AA 创作工具`。主品牌 `HaloCue`、仓库名、应用 ID 和数据目录继续保持不变。

## 5. 不在本次范围

- 不把主品牌改成 `AA 自动工具`。
- 不修改功能、模型流程或编译行为。
- 不重新生成图标。
- 不修改版本号或创建新 Release。
- 不把尚未实现的 AI 剧本创作写进当前产品介绍。

## 6. 验收标准

- GitHub 首页无需阅读全文即可看到 `AA 剧本自动演出工具`。
- README 准确描述“已有剧本到演出工程”的当前流程。
- 现有 GitHub 链接、Release 标签和下载附件继续有效。
- Android 桌面名称不被拉长，应用内可以看见中文定位。
- 任何展示文案都不夸大安卓端或未来 AI 剧本功能。
