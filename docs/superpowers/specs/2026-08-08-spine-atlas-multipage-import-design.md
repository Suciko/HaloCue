# Spine Atlas 多分页贴图导入设计

## 目标

角色骨骼导入必须复制 `.atlas` 声明的全部分页贴图，支持贴图位于角色素材目录的子目录中，避免导入后 Spine 资源因缺页失效。

## 方案

- 复用现有 atlas page 解析结果，将每个 page 解析为相对角色资源目录的安全路径。
- 校验阶段要求每个 page 是角色资源目录内存在的文件；路径越界、绝对路径和缺失文件都拒绝导入。
- `validate_spine` 在 `metadata["files"]` 中保留原有 `skel`、`atlas`、`texture`、`avatar`，并新增 `atlas_pages` 映射和 `all_files` 列表。
- 暂存和注册统一消费 `all_files`，按相对路径复制，文件摘要也覆盖全部资源。
- 没有 `all_files` 的旧测试/旧候选继续回退到原有四文件清单。

## 验收

- 多分页 atlas 能通过校验，元数据列出所有分页贴图。
- 子目录分页贴图在项目目录和存档目录中保持相对路径。
- 缺失分页贴图仍返回 `atlas_page_missing`，不产生部分安装。
- 现有单分页角色测试和完整素材测试保持通过。
