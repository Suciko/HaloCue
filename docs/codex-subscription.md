# Codex 订阅连接（源码候选）

此功能属于 Issue #44 的源码候选，已发布的 Beta 2 ZIP 尚不包含它。
写作助手和 AA 演出助手可以使用 ChatGPT 账号的 Codex 订阅额度。
Codex 的额度与账号下其他 Codex 使用共享，不能按每次请求换算成 API 费用。

1. 新版 Windows 包内置官方 Codex 运行程序；旧包需要安装官方 Codex CLI。
2. 打开「设置 → 模型服务 → 模型连接」，选择「Codex 订阅」。
   若未自动找到程序，在「安装位置」指定 `codex.exe`。
3. 点击「登录 ChatGPT」，在官方登录页面完成登录。
   HaloCue 使用自己的登录目录，不会读取或替换你平时 Codex 的登录文件。
4. 在账号的计费设置中关闭额外付费用量，再勾选面板中的确认项。
   HaloCue 不能替你验证或关闭这个账号设置。
5. 选择模型和用途：写作与 AA 演出、仅写作或仅 AA 演出。
   设置单次请求超时（5–600 秒），点击「测试并启用」。连接测试会消耗少量订阅额度。
   AA 演出测试会使用实际的演出输出 Schema；它不生成正式草稿。

「已登录」只表示账号与额度可以读取，不能证明模型请求成功。Windows
下优先保留显式代理环境变量；未配置代理时，Codex 子进程会使用当前用户
的静态系统代理与绕过列表。此处理不修改系统代理或父进程环境，也不解析 PAC。
失败时显示模型服务的错误消息和 HTTP 状态，不会用「任务未完成」隐藏具体原因。

演出请求达到超时时会保存已完成分块的检查点。点击继续时，未完成部分使用
更小的分块；修改模型配置后检查点仍需要按配置一致性规则重新生成。

登录状态、模型选择、额度和用途位于同一个配置面板。启用后进入仅订阅
模式，旧 API 配置保留但停用。登录失效、额度耗尽或模型错误会停止生成，
不会自动切换到付费 API。仍可以手动编辑和审查已有内容。

写作仍先生成候选，采纳才会更改正式正文。演出结果仍需人工审查。
本次接入支持文本写作与文本演出标注；图片素材识别尚不支持 Codex。

用量记录显示原生任务上报的输入、输出和缓存 token。工具往返属于同一
任务；软件看不到 CLI 内部每一次 HTTP 请求。不提供虚构的零元金额。
输出 token 少可能是短连接测试、简短修改或紧凑 JSON，应结合实际任务
和完整回执判断，不能直接当作生成失败。

登录凭据和个人数据保存在用户数据目录，不能上传到 Git、分享项目或
截图公开的登录链接中。程序退出时只关闭它自己启动的 Codex 子进程。

技术边界和验收证据见 [ADR 0007](adr/0007-codex-subscription-provider.md)
及 [接入验收记录](handoffs/2026-10-03-1.0-codex-subscription.md)。
