# 完成第一场

## 最短流程

1. 点“选择剧本”，打开 `.txt` 或 `.md` 文件。
2. 在“作品”里填写作品名，确认全作方向。
3. 建立卷、章和场景。
4. 在正文中写对白和旁白。推荐一行一个说话者：

   ```text
   老师: 久等了。
   乃爱: 我们现在出发吧。
   ```

5. 需要 AI 时，先在设置里测试模型；不需要 AI 时选择“仅转换格式”。
6. 生成审查草稿，逐张检查卡片。AI 的建议不会直接改正文。
7. 通过审查后发布 ScriptRelease。
8. 进入 AA 制作，补齐角色、背景和音效，最后编译并安装。

## 完成的标志

发布页显示审查通过，AA 制作页没有待处理问题，并且已经生成可安装的工程文件。
