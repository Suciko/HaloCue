# AI 和 Agent

## 两种模型状态

Fake Provider 只用于测试界面和接口，不能当作真实创作结果。API Provider 需要填写地址、模型名和 API Key，并先点“测试文字”。Codex 订阅连接使用本机 ChatGPT 登录；外部 Agent 的 MCP 连接则由外部软件运行模型。

## Agent 能做什么

Agent 可以根据场景正文、人物卡和已确认资料提出演出建议，也可以生成审查项。它不会直接发布正文，也不会绕过人工审查修改 ScriptRelease。

## 失败时怎么处理

网络超时、429 或 5xx 通常可以重试。配置变更后，旧任务会停止写入结果，需要用当前配置重新开始。取消任务后，迟到的模型结果会被丢弃。


## 用量和费用怎么看

在场景候选的“运行详情”及对话的技术详情中，可以查看已记录的用量。
“用量未报告”不等于零消耗；“统计不完整”或“已报告部分”表示仍有缺失信息。
缓存状态未知、不支持缓存和明确未命中不是同一回事。

费用按当前配置的单价估算，不是服务商账单。失败、截断或拒绝的响应如果带有
用量，仍会记录；取消后已发出的请求也可能产生费用，但晚到正文不会被采纳。
当前汇总只覆盖已记录的逻辑调用信息，尚不能保证包含所有传输层重试或服务器
中断时的消耗，也不构成硬性花费上限。

## 在外部 Agent 对话中制作 AA 演出

在一体化工作区的「设置 → 模型服务 → 通过外部 Agent 操作 HaloCue」中，勾选允许访问的 AA 制作任务，再把生成的 MCP 配置添加到 Agent 软件。可只选择 AA 任务；旧任务和独立导入的剧本也能使用，不需要导出任务包。HC 保持打开，外部软件负责模型和账号。

新剧本先用「仅转换格式」建立制作草稿，无需配置 HC 的演出模型；已有任务可直接使用。先在 HC 确认角色映射与需要的素材。之后可以直接对 Agent 说：

> 读取「第一章」的 AA 草稿，给爱丽丝这段对白安排表情、站位和停顿，用任务里已有的背景和音效。保持台词原文，提交演出建议让我看。

Agent 可以定位任务、分段读卡、查看冻结表情与动作选项，成批提出演出字段修改或插入指令。背景和音效须使用任务已冻结的素材键；新素材导入和人物映射仍在 HC 完成。表情须属于说话者当前映射的角色。

Agent 返回后打开任务链接，或在逐卡审查中点击「刷新建议」。先看前后对比，再选「采用演出建议」或「拒绝建议」。采用后修改进入逐卡审查及草稿预览，仍需确认卡片后才能编译；原始发布剧本不变。拒绝不改草稿。草稿变化后，旧建议需重新读取再提交。

当前是 1.0 源码预览功能。官方 MCP 客户端与本机工作区已验证；各外部软件的配置导入方式和订阅权限需按实际软件验证。HC 不获取外部账号的账单，也不代替外部 Agent 调用其模型。草稿预览不代表 AA 原生动画、声音与节奏已经验证。
