# AI 和 Agent

## 两种模型状态

Fake Provider 只用于测试界面和接口，不能当作真实创作结果。真实 Provider 需要填写地址、模型名和 API Key，并先点“测试文字”。

## Agent 能做什么

Agent 可以根据场景正文、人物卡和已确认资料提出演出建议，也可以生成审查项。它不会直接发布正文，也不会绕过人工审查修改 ScriptRelease。

## 失败时怎么处理

网络超时、429 或 5xx 通常可以重试。配置变更后，旧任务会停止写入结果，需要用当前配置重新开始。取消任务后，迟到的模型结果会被丢弃。


## 用量和费用怎么看

在场景候选的“运行详情”及对话的技术详情中，可以查看已记录的用量。
“用量未报告”不等于零消耗；“统计不完整”或“已报告部分”表示仍有缺失信息。
缓存状态未知、不支持缓存和明确未命中不是同一回事。

费用按当前配置的单价估算，不是服务商账单。失败、截断或拒绝的响应如果带有
用量，仍会记录；取消后已发出的请求也可能产生费用，但晚到正文不会被采纳。
当前汇总只覆盖已记录的逻辑调用信息，尚不能保证包含所有传输层重试或服务器
中断时的消耗，也不构成硬性花费上限。
