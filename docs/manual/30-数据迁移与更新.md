# 数据、备份、迁移和更新

## 数据在哪里

正式 Windows ZIP 的默认目录是 `%LOCALAPPDATA%\\HaloCue`。程序文件和用户作品分开保存，更新只替换程序目录。

## 0.9.3 迁移

发现旧数据后，先点“先备份”，再选择“备份并导入”。系统只复制已知配置和数据库文件，不覆盖已经存在的 1.0 文件。迁移失败时，旧目录和备份都保留。

集成写作数据位于 `integrated/writing`，制作数据位于 `integrated/production`。退出后备份整个 HaloCue 用户数据目录。源码集成服务仍使用 `.halocue/integrated`；独立服务或显式自定义路径请备份实际数据目录。

## 手动更新（集成界面）

退出 HaloCue 并备份用户数据，把新 ZIP 完整解压到新的程序目录后启动。程序继续使用同一个用户数据目录。

## 自动更新（兼容制作界面）

程序启动后会后台检查签名清单。发现新版本时只提示，不会静默安装。

使用 `HaloCue.exe --legacy-ui` 时，在工作台顶部点“下载并校验”，等状态变成“更新包已准备好”，再点“退出并更新”。HaloCue 会先保存更新状态，然后退出；包内的 `HaloCueUpdater.exe` 会等待旧进程结束，替换程序并重新启动。更新失败会保留旧版本并恢复备份。

如果网络中断或更新源暂时不可用，工作台仍然可以继续使用，也可以点“手动下载”从 Release 页面获取压缩包。
