# 故障排查

| 现象 | 先做什么 |
|---|---|
| 窗口打不开 | 确认 WebView2，退出其他 HaloCue 实例 |
| 模型连接失败 | 检查地址、模型名和 Key，重新测试文字连接 |
| 找不到 AA | 重新选择真实的 `AzureArchive.exe` |
| 找不到 Spine | 只在需要骨骼功能时配置自己的 Spine |
| 端口冲突 | 退出占用程序，或用 `--port` 指定其他本机端口 |
| 更新失败 | 保留旧版本，检查网络、磁盘空间和安装目录权限 |
| 迁移失败 | 不删除旧目录，从时间戳备份恢复后再试 |

如果仍然无法解决，请在设置中复制运行环境诊断。诊断不包含 API Key、正文和个人素材路径。
