# 安装与第一次启动

## 这页解决什么问题

你会把 HaloCue 解压到电脑上，打开程序，并完成第一次环境检查。

## 需要准备

- Windows 10 或 Windows 11，64 位。
- Microsoft Edge WebView2 Runtime。
- 你自己安装的 AzureArchive。HaloCue 不附带游戏文件。

## 操作步骤

1. 下载 `HaloCue-1.0.0-windows-x64.zip`。
2. 把 ZIP 完整解压到一个你有写入权限的文件夹。不要直接在压缩包预览窗口里运行。
3. 双击 `HaloCue.exe`。
4. 第一次打开时，在“设置”里选择 `AzureArchive.exe`。
5. 等待“运行环境”检查完成。没有配置 Spine 或模型时，相关功能会显示为不可用，普通剧本编辑仍可使用。

## 打不开怎么办

先退出已经打开的 HaloCue，再确认 WebView2 Runtime 已安装。如果窗口仍然打不开，运行同目录的“检查运行环境.cmd”，把最后一段错误信息保存下来。
