# 0.95 V10 演出链路接入记录

当前源码入口和统一发布包的生成管线标记为 `0.95`，导演提示词标记为
`v10-canonical-emo-protocol`。正式交付沿用既有的 PyInstaller one-directory +
WebView2 桌面链路，用户通过 `HaloCue.exe` 启动；源码检查包使用
`prepare_release.py --release-095`。

## 两步到 AAP

正常入口使用同一套当前提示词和后端，顺序是：

1. `preflight`：通读当前剧本，识别角色、物理场景和背景需求；背景库以已标注的
   地点、分类、时间、氛围、阵营、搜索词和复用信息作为语义候选。
2. `annotate`：G1 场景事件规划 + G2 逐节点导演决策，随后执行
   `compact -> validate -> policy -> AAP compile`。

0.95 的网页草稿入口与直接构建入口都默认启用当前 G1 + G2，并把 preflight 的
`usage_chain` 原样交给标注阶段；诊断时仍可显式设置 `scene_event_planning=false`，CLI
也可使用 `--no-scene-plan`。这样盲测使用的 V10 提示词不是只存在于测试脚本中。

旁白和具名画外音保持剧情语义，但不进入立绘、站位、表情、动作或镜头名单；
画面内角色可以通过 `reactions` 承接他们带来的刺激。最终仍由协议和编译器检查
资源、生命周期、位置、几何和单镜人数。

## 数据库边界

`aa_assets.db` 是当前 0.95 运行的标注事实源，默认以只读连接提供 face、表情语义、
场景标签和背景检索事实。项目专用 `*.resources.json` 是本次运行的资源快照，不再
通过“在快照旁边寻找 aa_assets.db”的隐式约定加载数据库。

`annotate.py --database <path>` 可以显式追加第二个已经确认的只读标注数据库；多个
数据库只做已存在资源的语义能力叠加，不会凭空引入没有资源文件的 AA key；不覆盖、不迁移、不写入任一来源。网页入口可在
`aa_config.json` 的 `asset_databases` 数组（或 `HALOCUE_ASSET_DATABASES` 环境变量）中
配置同样的只读叠加列表，主库始终优先。未确认来源身份前，不自动把 1.0 工作区或历史
盲测副本当作第二事实源；`setup_status` 会返回实际使用的 `paths` 和 `count`。当前工作区
已按用户指定在 `aa_config.json` 中显式登记两份大库：0.95 主库优先，交接包数据库只读
补充。旧库缺少新版 `backend_json` / `observation_json` 时按“没有附加来源元数据”读取，
不会迁移旧库，也不会因此丢弃它原有的表情语义。

## 背景分类与搜索

背景的 `scene_visual_label` 会保留 `main_category`、中文子分类、室内外、时间、天气、
季节、氛围、阵营、复用范围、`tags` 和 `search_terms_cn`。背景选择 API 会递归搜索整条
标签记录，因此用户已经标注的分类、近义词、阵营名和描述都能命中；已确认 CG、标题卡和
效果资源不会进入可持续对白背景候选。

## 可复核产物

每次真实生成应在独立输出目录保留原始请求/响应、G1/G2 中间结果、最终 AAP、trace 和
`.model-audit.json`。trace 的 `pipeline` 字段记录 0.95、V10 提示词修订和实际只读
数据库路径，preflight 目录的 `input-manifest.json` 还记录两份数据库的大小和 SHA256，
便于判断字段是 AI 新生成、数据候选缺失还是后端链路丢失。

## 0.95 发布包

统一发布包包含运行所需的 0.95 Python 模块、提示词、背景分类检索、全量表情语义、
Spine 相关程序模块，以及经过路径清理的主标注数据库和只读叠加数据库。数据库只保留
资源名称和标注元数据，不包含 AA 图片、音频、Spine 骨骼或其他游戏素材。

```powershell
python prepare_release.py --release-095 -o ..\release-output\0.95
python build_desktop_release.py --output-parent ..\发布包
```

包内 `aa/aa_config.json` 使用相对路径登记数据库；启动器仍会要求使用者在本机选择
AzureArchive 工作区和模型接口。0.95 统一使用同一个发布包，不再区分公有包和私有包；正式发布物为
`HaloCue-0.95-windows-x64` 目录及对应 ZIP，程序入口是 `HaloCue.exe`。

AA 本机人物目录、繁简译名匹配和公开包私有人物清理的实现边界，以及后续 1.0
需要同步的字段与测试，见 `docs/0.95-to-1.0-aa-manifest-handoff.md`。
