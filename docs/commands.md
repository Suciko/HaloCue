# 指令速查

三类东西写在三个不同的地方，别搞混：

| 写在哪 | 是什么 | 剧本里怎么写 |
|---|---|---|
| `additionalPrompt` 字段 | 额外指令，控制画面与流程 | `@wait` `@bgshake` `@zoom` `@st` `@raw` |
| `text` 字段里 | 文字样式标记，只影响对话框里的字 | 直接写进台词 |
| 结构化字段 | 背景/过渡/音效/表情等 | `@bg` `@trans` `@se` `(05)` `[惊叹]` |

---

## 一、额外指令（写进 additionalPrompt）

### `#wait;毫秒`

最基础的一条。**注意编译器会自动插 wait**（有气泡 2500 / 有动作 1500），
你写的是**覆盖**不是叠加。详见 `direction.md`。

剧本写法：`@wait 2500`

从 1 号位移到 2 号位约需 200–300ms，每多一段距离时间叠加。

### `#bgshake`

背景抖一下。想持续抖就连着建多个脚本，每个配 `#wait;100`。

剧本写法：`@bgshake`

实测用量：14 次（139 个工程）。

### `#zmc;模式;X,Y;缩放系数;持续时间`

背景平移与缩放。把坐标 (X,Y) 处移到原点，并以该点为中心缩放。

- 模式 `instant`：瞬间变换，不需要持续时间
- 模式 `smooth`：平滑变换，必须给持续时间
- 缩放系数 = `3160 / 倍数`。小于 3160 是放大，大于是缩小
- 编辑模式下切到下一个脚本会变回原样，鉴赏模式会一直保持到换背景

剧本写法：
```
@zoom instant 300,-150 2160
@zoom smooth -650,-450 1860 500
```

实测用量 44 次。实测参数范围：X −700～500，Y −380～500。

> 社区文档说"背景变换指令后面必须跟 wait"，但实测 44 条 `#zmc` **没有一条**
> 与 `#wait` 同脚本共现。默认 wait 一直都在，所以不必刻意补。

### `#st` / `#stm` 屏幕文字浮现

```
#st;[X,Y];模式;字体大小;      左对齐，X,Y 是文字左端
#stm;[X,Y];模式;字体大小;     居中，X,Y 是文字中心
```

- 模式：`instant` 瞬现 / `smooth` 整条淡入 / `serial` 从左到右逐字
- 字体大小 50 = 原大小
- **结尾的英文分号必须写**，否则指令无效
- X 轴宽度固定 2960 单位；Y 轴因设备而异，会错位

剧本写法：
```
@st [-1200,-430] serial 60
@stm [0,-430] instant 90
```

实测：`#st` 17 次（serial 11 / smooth 6），`#stm` 23 次（serial 22 / instant 1）。
`#stm` 的 X 恒为 0。`#st` 的 X 实测只出现过 −1390 / −1300 / −1150 / −1100 / −900。

用它做**无对话框对话**需要四个脚本配合，见社区文档原文。

### `#clearST`

清除屏幕上所有浮现文字。实测 40 次，其中 7 次与 `#wait;200` 成对。

剧本写法：`@clearst`

> 社区文档提醒：这条指令有概率触发未知错误导致 AA 异常，退出项目重进可解。

### `#N;fx;{shot}` 射击特效

N 是人物位置 1–5，**不能填 0**，且该位置必须有角色，否则无效。
多人同时中弹就写多行。

剧本写法：手工指定槽位时用 `@shot 3`；自动标注和普通剧本推荐写 `@shot 凯伊`。
后者会在排布完成后转换成凯伊当前所在的 `#N;fx;{shot}`。若凯伊不在这一镜，程序会警告并忽略，绝不会把特效误套到其他角色或空槽位。

实测 5 次，集中在 1 个文件。

### `#fx;AronaTouch`

序章 ARONA 指纹识别的特效。

剧本写法：`@aronatouch`

> 语法来自社区文档。二进制里能找到 `AronaTouch` 字面量，但没找到对应的
> fx 动画类，**未经实测验证**。用不了的话就别用。

### `#hidemenu` / `#showmenu`

隐藏 / 恢复右上角菜单。只在鉴赏模式看得到效果。

剧本写法：`@hidemenu` `@showmenu`

> 字面量存在于二进制中，`Scenario` 类也有 `get_showMenu/set_showMenu`，
> 但在 139 个工程和全部 .aas 里**出现 0 次**，属于未实测。

### `#raw` 逃生舱

任何本工具没包装的指令，原样写入：

```
@raw #任意指令
```

可以重复写多行，按顺序进同一个 `additionalPrompt`。

### 编译器自动生成的（不用你写）

`#na;` 旁白 / `#title;` 标题 / `#place;` 地点 / `#continued` 续接 /
`#nextepisode;` 下一话 / `#N;hide` 隐藏 / `#N;mK` 移动 / `#N;a` `#N;d` 进出场 /
`#N;h` 高亮 / `#N;em;` 气泡 / `#N;closeup` 特写 / `#wait` 默认停顿。
Chat（原生 `[재잘]`）编译为 `#N;em;[재잘]`，而 Jump 是动作 6，编译为
`#N;jump`；两者不可互换。`additionalPrompt` 仅接受作者显式写下的高级指令
（如 `@raw`），模型输出不会直接写入该字段。

## 二、对话框文字标记（写进台词里）

转换器不处理这些，原样传给 AA。

| 写法 | 效果 | 实测用量 |
|---|---|---|
| `[RRGGBB]文字[-]` | 变色，`[-]` 决定染色止于何处 | 26 次 |
| `[size=大小]文本[/size]` | 缩放，**60 = 原大小** | 45 次 |
| `[ruby=注音]文本[/ruby]` | 注音（注音部分不受变色影响） | 0 次 |
| `[b]文本[/b]` | 加粗 | 0 次 |
| `[i]文本[/i]` | 斜体 | 0 次 |
| `[u]文本[/u]` | 下划线 | 0 次 |
| `[s]文本[/s]` | 删除线 | 0 次 |
| `[sup]文本[/sup]` | 上标 | 0 次 |
| `[sub]文本[/sub]` | 下标 | 0 次 |
| `[两位数]文本` | 透明度，`00` 最透明；另有 `a0`–`f9` 形式 | 0 次 |

常用色：组织名的淡蓝色是 `[7cd0ff]`，红 `[FF0000]`，青 `[00FFFF]`。

**嵌套有顺序要求**：`[size=100][ruby=x]文本[/ruby][/size]` 正确，
反过来只有 size 生效。下划线与删除线不兼容，上标与下标不兼容。

> 注意：`[b] [i] [u] [s] [sup] [sub]` 这六个来自社区文档，但在 139 个工程和
> 游戏二进制里**都找到 0 次**。用之前先在 AA 里试一下。
> 实际被验证在用的只有 `[颜色]…[-]` 和 `[size=]…[/size]`。
> 社区文档说"嵌套已验证最多九层"，语料里真实最大嵌套深度是 **1**。

## 三、结构化字段

见 `python script2aap.py --syntax`。

| AA 面板 | 字段 | 剧本写法 |
|---|---|---|
| 背景图片 | `bgName` / `bgFriendlyName` | `@bg BG_GameDevRoom` |
| 过渡 | `transition` | `@trans 淡入淡出 1500` |
| 背景效果 | `bgEffect` | `@bgfx 集中线` |
| 弹出图片 | `popup` | `@popup Event03_CH0070` |
| 背景音乐 | `bgmId` | `@bgm 999`（999 = 静音） |
| 音效 | `sound` | `@se SE_DoorOpen_01` |
| 地点名称 | `placeText` | `@place 千年科技学园` |
| 角色·表情 | `faceId` | `(05)` |
| 角色·表情符号 | `emoticon` | `[惊叹]` |
| 角色·动作 | `action` | `{jump}` |
| 角色·效果 | `shapeOverride` | `<特写>` |
| 角色·地位 | `speakerSlotNum` / `highlightedSlotNums` | 自动；`@hl` 覆盖 |
| 角色·位置 | `startingPos` / `endingPos` / `appear` | 自动；`@move` `@enter` `@exit` |

`effect` 字段在 112770 条记录里恒为 0，确认未使用。

### 过渡的完整列表

UI 上的 4 个按钮是分组，组里再选时长：

| 分组 | 本地化名 | 条目 |
|---|---|---|
| Fade | 淡入淡出 | 23 条（250/500/1000/1500/2000/2500/3000/4000/5000 双向，以及单向进/出） |
| Fade White | 淡入淡出（白） | 21 条 |
| Crossfade | 交叉渐变 | 10 条（200–4000，只有单向） |
| Special | 特殊 | 6 条：Swipe R/L/D/U、Noise、Circle |

中文简写见 `tables.TRANS_CN`，写 `@trans 淡入淡出 2000` 即可。
名字里的 `>>` 是切换点：`Fade 1000 >> 1000` = 淡出 1s 后切场再淡入 1s，
`Fade 1000 >>` 只淡出，`Fade >> 1000` 只淡入。

### 背景效果的完整列表

见 `tables.BGEFFECT`（26 条）和 `tables.BGFX_CN`（中文别名）。
全部对应 catalog 里真实存在的 `UI_FX_<name>.prefab`。
