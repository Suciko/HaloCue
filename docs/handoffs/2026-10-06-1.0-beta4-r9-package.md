## 命令与复验入口

本机实际执行了私有 `.tmp/` UTF-8 QA 脚本，完整日志/隔离夹具保留于维护者本地 E 盘，不是共享先决条件：

```text
python -X utf8 .tmp/build-r9.py
python -X utf8 .tmp/r9-native-acceptance.py
python -X utf8 .tmp/r9-mcp-acceptance.py
python -X utf8 .tmp/r9-research-check.py
python -X utf8 .tmp/r9-frozen-acceptance.py
python -X utf8 .tmp/r9-portable-check.py
全部 exit 0；构建与最终包扫描、窗口、MCP、资料、ZIP/启动检查通过。

python -X utf8 .tmp/r9-aa-acceptance.py
编译与之前断言通过，安装处 exit 1 / HTTP 423。

python -X utf8 .tmp/r9-aa-finish.py
exit 0，解析编译成品并确认 aa_running 保护，记录 installation_status=blocked_by_running_user_aa。

python -X utf8 .tmp/r9-frozen-ui.py
精确 ZIP 解压 exe 服务，内部浏览器人工检查；认证停止后 exit 0。

python -X utf8 .tmp/r9-ui-receipt.py
python -X utf8 .tmp/finalize-r9.py
exit 0；生成七张 16:9 图像证据及真实状态交付收据。
```

其他机器可在源码提交上使用正式入口复建，不依赖私有脚本：

```text
python tools/export_public_source.py --source <REPO> --output <BUILD_ROOT>/source/HaloCue --build-root <BUILD_ROOT>
python tools/build_public_release.py --source <BUILD_ROOT>/source/HaloCue --output <BUILD_ROOT>/artifacts --python-executable <BUILD_PYTHON> --node-executable <NODE>
python tools/verify_portable_release.py <ZIP> --root <FRESH_DRIVE_ROOT_QA> --keep
```

工具临时目录应指定到有足够可写空间的盘。QA 脚本的一次截图格式断言失败是把内部浏览器返回的 JPEG 当作 PNG；读取真实格式、仅更正文件扩展名后收据生成通过，没有改动产品或图像内容。
