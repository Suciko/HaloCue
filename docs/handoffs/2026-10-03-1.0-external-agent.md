## Delivered

An author creates a task for an explicit window of saved scene prose (1–40
paragraphs). The nearby External Agent entry exports a frozen JSON package and
accepts a JSON file/paste result. MCP-capable external hosts can use a single-task
stdio bridge. Both paths create the existing pending scene proposal; only author
acceptance changes the formal revision. The author can recover/revoke tasks,
refresh MCP state and open the returned inline candidate.

Pinned revision/input/paragraph hashes, strict fields, scoped blocks, duplicate
retry, pending-proposal conflicts and expiry are checked on the server. Task
records survive service restart and project backup; private connection files do
not enter the archive. Old backups initialize the additive table during restore.
Connection file write failure rolls back task creation. MCP readiness is checked
before offering a usable configuration; file exchange stays available without it.

Decisions: [ADR 0008](../adr/0008-scoped-external-agent-tasks.md).

(`mcp>=1.30,<2`), preferably a separate `.venv-agent`. No public release artifact
was rebuilt or replaced. The existing Codex subscription lock remains in effect.
