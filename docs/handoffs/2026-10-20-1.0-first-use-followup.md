## 修正的实际断点

接续[聚光教学交接](2026-10-20-1.0-first-use-spotlight.md)，产品与教学边界仍以[方案第 0 节](../1.0-guided-workflow-plan-2026-10-19.md#0-同日纠正与当前交付边界)为准。

1. 面板宽度改变时，输入框移动而聚光停在原处。原来只观察 `body` 尺寸，固定窗口内的列宽变化不会触发它。现在观察当前目标及其布局祖先，继续用一帧一次的定位更新；退出或重选目标时解除旧观察。正文与输入框不重建。
2. 阅读模式里没有“开始写作”和编辑输入框，教学却仍要求操作它们，导致全屏压暗但没有可用目标。现在手写和未保存内容先指向真实“编辑”按钮，切换后接回输入/保存。可直接操作的候选审查和助手输入仍沿用原入口；不自动切换模式或采纳候选。

改动为 `services/halocue/writing/web/first-use-task.js`、该脚本缓存版本及对应状态/浏览器测试。没有新增依赖、API、合同、schema、迁移或模型请求，未改 1.1。

## Web Control 实操

使用独立 loopback 服务和两份临时合成作品，未操作真实作品、凭据或 AA 安装；未发送助手消息或调用付费模型。

- 帮助重看 → 输入尚未发送的要求 → 键盘调整右栏至 280 像素 → 实际拖动至 380 像素。输入仍完整；拖动后表单左沿为 918、聚光左沿为 913，保留设计的 5 像素留白。小指针未遮挡输入。
- 暂停 → 帮助显示“继续首次创作教学” → 继续 → 选择自己写 → 写第一段 → 保存，完成提示出现且遮罩退出。
- 打开另一份已有正文，确认完成后不自动教学 → 切阅读 → 帮助主动重看。高亮“编辑”按钮并显示相应说明；点编辑后原句保留，修改保存产生第 2 版并立即退出教学。最终页面 console warn/error 查询为 0。

实操截图仅含合成作品，保留在维护者本机交付目录，非异机前置条件：`web-control-panel-resize-followup.jpg`、`web-control-read-to-edit-followup.jpg`、`web-control-followup-complete.jpg`。临时页与服务在验收后关闭。隔离服务仍未挂载帮助正文，加载失败提示只作为夹具局限记录，未更改安装包帮助行为。
