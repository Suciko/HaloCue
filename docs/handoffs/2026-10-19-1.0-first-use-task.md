## 纠正与实际行为

最初 G1 侧重日常持续陪跑，未抓准首次使用需求。[早期交接](2026-10-19-1.0-guided-authoring-g1.md)保留其历史测试收据；当前默认行为由本文取代。1.1 仓库未修改。

新增 `services/halocue/writing/web/first-use-task.js`，沿用 1.0 页面、主题令牌、命令和正文候选审查。

1. 真正的空白工作区首次提供“带我开始”或跳过。有作品、正在打开作品或既有界面导览记录时，不自动展示教学。
2. 点击开始后建立作者自己的作品。没有自动建样例，也不复制或生成正文。
3. 作者可以写下构思并沿用现有 Agent 下一步，也可以“先自己写”。无模型时手写路径可走通。
4. 进入自己的第一场正文：草稿提示保存；AI 候选解释改前/改后和明确应用，教学按钮只定位审查，不代为采纳。
5. 检测到目标场景新的正式正文修订后，教学完成。完成表示第一段教学闭环，不能当作全章、全作或 AA 已完成。

完成和跳过保存在浏览器学习记录 `halocue:onboarding:authoring-v1`，之后刷新或建立新作品不自动重播；暂停后需从帮助/设置主动继续。记录只含状态、作品/场景及开始时修订标识，不含正文。当前不跨浏览器/设备同步；本地存储不可用时只提供当次会话行为。

主动重看已有作品时，以开始重看的正式版本为基线，需要新保存/采纳才算本次完成；暂停继续保留基线。切换作品提示返回教学作品，删除教学场景需显式重新选择，不把其他作品或旧正文算成学习进度。

构思页教学位于标题下方、对话滚动区之外，避免自动滚到底部裁掉提示；正文页教学紧邻当前编辑内容。被动步骤更新不自动切页、滚动或抢输入焦点；主动开始/重看会滚到教学卡片，定位动作由作者点击。步骤随事实更新，不用连续点击“下一步”假装完成。

原 `guided-workflow.js` 默认改为自由创作，不显示模式工具栏；日常持续陪跑需从设置主动开启。原 Agent 回复小按钮保留。已有显式保存的陪跑偏好仍尊重，教学完成后回到自由创作。

无新增模型请求、API、合同、schema 或数据库迁移。不涉及真实作品、AA 安装、1.1、打包或发布。
