## 修改范围

首次引导去掉反复出现的“点亮起的……”和说明书式的解释，直接说明当前操作。保存、采用候选、资料选择、模型用量及重试的含义保留。比如“先审查，再采用助手的文字”改为“看看这段写得怎么样”，说明仍明确勾选后点“应用”即保存正文。

相邻界面将“本场上下文 / 当前作用域”改为“本场参考资料”，“保存本场上下文”改为“保存资料选择”，“沉淀本场变化”改为“记录本场进展”。同步调整对应提示、资料库空状态、跳过记录和发布前提醒。新建作品的说明也改为简短中文。

只改显示文字和相关旧测试的文案断言，不改变工具、API、字段、保存/采用/记忆确认逻辑、引导状态或布局。不改作品正文、模型生成文本或历史记录。个人用语润色 Skill 不作为异机依赖；重复验收仍见[既有未激活提案](../agents/skill-proposals/isolated-1.0-acceptance.md)。
