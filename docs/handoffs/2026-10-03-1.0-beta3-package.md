## Change and build provenance

The portable bundle now includes `HaloCueMCP.exe`, a separate console worker sharing `_internal` libraries with the windowed GUI. Frozen workspace and legacy task configurations launch that worker directly, without Python or a source checkout. The worker probes its collected SDK before profiles are exported; an incomplete extraction gives an explicit error. Public source selection includes the Codex/MCP boundary modules and MCP requirements, and the builder refuses to finalize a bundle missing the worker.

Main, worker and updater Windows ProductVersion values were read from the actual PE files and are all `1.0.0-beta.3`. Python/package version, archive identity, changelog and local preview notes agree. See [Beta 3 notes](../releases/1.0.0-beta.3.md).

Maintainer-local build environment: Windows x64, `E:/Miniconda3/python.exe` base (CPython 3.13.12), isolated `.tmp/beta3-build-venv` with system packages, PyInstaller 6.22.0 and MCP SDK 1.30.0. The overlay installs MCP requirements without changing the user's global environment. PyInstaller ran only against indexed public source in `build/beta3-20261003/source/HaloCue`. The notice audit refused finalization for missing `websockets`; installed metadata verifies websockets 13.1 / BSD-3-Clause. Both shipped copies of the notice are corrected; the corrected notice audit passes for 23 detected components.

The first full public scan then refused the new worker outside the existing executable allowlist and a JSON Schema benchmark fixture. Pushed packaging-policy correction `b90c72d02e469e871982ffe4286e0978786566e2` admits only the root worker in public/private modes and trims `jsonschema/benchmarks` during normal or existing-bundle finalization, preserving the runtime schema resources. Arbitrary/nested EXEs and unsafe JSON remain rejected. GUI/worker runtime files and PyInstaller specs were unchanged by these corrections.

Final source snapshot `build/beta3-20261003/source-policy/HaloCue` is copied from the verified, scanned `source-final/HaloCue` export and resealed with four exact indexed packaging-policy/test files from that commit. Public selection has the same path set; the hash manifest is verified before and after the refresh. A local orchestration script calls the existing `finalize_existing_bundle` API, which performs full source and public scans before writing the archive; no scan is skipped. Collaborators can reproduce with normal indexed source export plus `tools/build_public_release.py`, without the local script. Final scans and archive finalization passed (exit 0).
