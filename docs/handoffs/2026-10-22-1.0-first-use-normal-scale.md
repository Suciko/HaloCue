## 显示标准与实测

后续首次教学主验收使用 **1920×1080 内容视口、16:9、浏览器 100% 缩放**；1600×900 为另一组正常桌面尺寸，1280×720 和 960×640 保留为适配补测。截图保存完整视口，不裁切或后期放大来代替布局验证。

上一轮[语义交接](2026-10-21-1.0-first-use-meaning.md)中的截图为 1280×720，虽然也是 16:9，但没有单独记录浏览器 zoom。不能从这张截图断言当时浏览器被放大，也不能据此代表较大桌面的布局体验。

本轮 Web Control 在两组正常桌面尺寸读取 `Page.getLayoutMetrics`：`cssVisualViewport` 分别为 1920×1080、1600×900，`zoom=1`、`scale=1`；HTML/body 的 CSS zoom 均为 1，根字号 16px，引导正文 13px，无页面横向溢出。设备像素与 CSS 像素不能混用：此次宿主的 CDP 旧设备像素指标为 CSS 指标的 1.5 倍，截图及布局按明确的 CSS 内容视口记录。没有修改 Windows 显示缩放；本轮不是原生 Electron 窗口/系统 DPI 验收。

合成临时作品从既有待审正文主动重看教学，在两个尺寸核对高亮与指针。1920×1080 下取消一项、实际应用其余 5 项，正式正文显示第 1 版，遮罩退出。引导不遮住正文选择和应用操作，console warn/error 查询为 0。帮助正文未由此夹具挂载，不能将夹具的帮助载入提示归为产品回归。

维护者本机交付目录保留原尺寸 `review-1920x1080-100percent.jpg`、`review-1600x900-100percent.jpg`、`completed-1920x1080-100percent.jpg` 和两份布局指标 JSON，仅合成数据。临时页和服务已关闭，浏览器临时视口覆盖已 reset。
