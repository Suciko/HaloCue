# 2026-09-30 HaloCue 1.0 对话路由与 BA 资料验收

## 本轮范围

本轮继续验收 HaloCue 1.0 的写作 Agent、创作入口、原作资料边界和本地 UI；同时整理此前只保留在本机工作树、尚未上传的 1.0 改动。

维护原则：

- 用户能直接在对话中描述的工作交给 Agent 和工具执行，不再要求先点一个“形成全作方案”按钮。
- 用户只在采纳、退回、保存、冻结、发布或撤销等明确决策点操作。
- 正文、人物卡、世界观、作品事实和结构候选都先是 Proposal，未经用户确认不得成为正式资料。
- 不同创作意图进入不同路由：短篇、长篇、续写、小说改编剧本、人物关系场景、世界观先行、只做大纲、先做场景/剧本、导入草稿审查等。

## 本轮代码与 UI 证据

- 全作讨论页当前下一步显示“继续讨论”；信息足够后 Agent 自动整理候选，页面不再显示“形成全作方案”。
- 创作对话保留 BA 写作工作流、作品上下文和资料检索工具记录。
- 小说入口使用独立原文改编工作台，分为原文、计划、候选；正式正文只在用户采纳后改变。
- 人物库明确说明随软件提供的是 BA 元数据参考，不会自动成为人物卡或作品事实。
- 原作资料检索现在同时请求：
  - 可选的本机只读原作演出语料库；
  - 随软件提供的 `resources/search` BA 元数据索引。
- 当原作文本语料库不可用或没有匹配时，输入“白子”仍能看到人物索引、社团、服装数量和表情差分数量，并明确标记“仅作参考”。这避免了“系统说可检索、页面却没有结果”的误导。
- bundled metadata 仍不包含图片、音频、Spine、官方原文或用户作品文件；正式人物卡仍需用户确认。
