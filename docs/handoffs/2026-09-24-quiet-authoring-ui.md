## Implemented
- New scoped `web/authoring-ui.css` owns the authoring composition after theme injection. The core renderer appends this layer after its existing runtime theme reorder so production CSS order matches the intended design.
- Content/composer width is now **820 px**, not 900 px. Header content follows the same column; the thread scrollport still spans the workspace. Panel collapse state is not forced.
- Navigation shares theme materials rather than a fixed dark navy. Its existing palette tokens provide text/selection contrast. Both authoring routes use the existing outline icon set; production and other routes are unchanged.
- Unified composer surface: no separate tinted toolbar band, quieter attachment affordance, round send control, consistent spacing and focus treatment.
- Pending review uses natural-language one-line previews when closed; structure summaries prefer actual scene/chapter goals instead of serialized contract metadata. Complete values remain in the expanded pair.
- Counts omit zero-valued operation categories. Empty/invalid review warnings keep their existing semantics.
- Scoped, keyboard-accessible expand/collapse-all controls operate only on the current review. They never change acceptance checkboxes or call the API. Work review disclosures participate in the existing per-thread disclosure-memory hook.
- Scene modification header combines the selection and discussion actions, as sibling controls; clicking discussion cannot toggle acceptance. Redundant summary text is hidden while the complete pair is open. Mobile retains accessible discussion targets.
- Scene Agent user messages collapse only the exact context envelope generated by `sceneReviewDiscussionContext`, keeping the actual author question prominent and the entire original message inspectable. No persisted content is changed. Arbitrary user text is not treated as this envelope.
- Scene Agent replies use the existing escaped paragraph/list/heading renderer rather than a single undifferentiated text block. Existing long-reply disclosure remains.
- Existing candidate acceptance, version checks, discussion-only behavior, navigation guards and mobile round-trip flow are unchanged.
