# Handoff: 1.1 integration from the 1.0 runtime

## Baseline

The 1.1 editor stream is a successor to the committed `feature/1.0-runtime`
branch. It must not be based directly on the 0.95 root implementation or on a
standalone governance branch. This integration branch was created from
`origin/feature/1.0-runtime` at `30442d4` and then received the collaborator's
scene-preview commits through `370b300`.

The maintainer's uncommitted 1.0 worktree changes remain separate and were not
copied into this branch.

## Corrections

- default two-person stage layout is visible slots `1` and `5`;
- one-person and three-person layouts remain `3` and `1, 3, 5`;
- slots `2` and `4` remain available for explicit manual placement;
- the browser fixture assertions use the current Chinese display names.
