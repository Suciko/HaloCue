## 当前行为

本轮替代[前一天首版](2026-10-19-1.0-first-use-task.md)的内嵌教学卡片。状态边界继续以[方案第 0 节](../1.0-guided-workflow-plan-2026-10-19.md#0-同日纠正与当前交付边界)为准，1.1 仓库未改。

- 压暗周围、高亮当前实际控件，用无卡片背景的短文字和小箭头说明。用户操作原有新建、视图切换、添加场景、正文输入、保存及候选选择，不另建一套“教学版”主按钮。
- 表单和候选比较需要阅读及填写，保留整个操作区域明亮。指针避开输入框；输入、滚动、缩放及页面重绘后更新位置。遮罩不修改正文 DOM，不接管原有导航与草稿保护。
- 新建作品的自定义对话层和场景原生 dialog 都能正确挂载教学。打开模型设置、帮助或其他对话框时暂收遮罩，关闭后恢复，避免覆盖配置或确认操作。
- 从“先自己写”进入大纲后，下一项变成真实的“添加场景”。最小窗口中改指向视图下拉菜单；目录或 Agent 收起时先定位展开入口。
- 空白正文块或对白缺说话人时先提示填写，不催促无效保存。开始输入后仍保留可编辑正文明亮，保存按钮单独突出。
- 暂停后说明恢复位置，帮助/设置入口显示“继续首次创作教学”。已有内容重看保留版本基线；新正式正文修订产生后立即退出遮罩并显示完成提示，不再要求额外点击“完成”。
- 新用户直接点击原有新建按钮也能接上教学；开始、暂停、完成和跳过均保留浏览器学习记录。完成后刷新或建立下一部作品不重播，老用户不自动展示；持续陪跑仍需手动开启。

实现集中在 `services/halocue/writing/web/first-use-task.js`、`guided-workflow.css` 和 `index.html`，增加了对应纯状态/浏览器断言。无新增依赖、模型请求、API、合同、schema 或迁移。

## Web Control 实操与发现

使用两套临时数据、独立 loopback 服务与本地 Fake Provider，未操作作者真实作品、凭据或 AA 安装。

1. 从空白界面建立自己的作品，选手写、进入大纲、建场、输入并保存。初版暴露了大纲重复提示“打开大纲”以及新增空段即提示保存的问题；已修正，新的聚光呈现从实际教学进度继续实操。
2. 聚光首版直接点亮真实顶部导航，进入大纲后自动指向“添加场景”；打开表单可正常填写。后续正文输入未丢焦点，保存入口及编辑区域同时留亮。
3. 模拟候选单独验收：原位比较 6 项变化，取消其中 1 项，再明确应用 5 项。只有采纳后产生正式正文才完成教学。完整合成规则只验证操作链路，不代表真实模型质量。
4. 主动重看已有正文 → 暂停 → 刷新 → 帮助中的“继续首次创作教学” → 修改并保存，实际看到遮罩立即退出。最新该页 console warn/error 查询均为 0。

实际 Web Control 截图：`web-control-save-spotlight.jpg`、`web-control-review-spotlight.jpg`、`web-control-completed-no-overlay.jpg`，仅含合成作品，留在维护者本机交付目录；不作为异机前置条件。隔离轻量服务没有挂载帮助正文资源，帮助框显示载入失败；框内重看/继续入口正常。未据此宣称或修改安装包的帮助正文行为。
