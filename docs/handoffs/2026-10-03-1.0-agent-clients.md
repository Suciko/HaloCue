## Delivered

The connection-settings selector exports Codex TOML, Claude Code JSON or generic JSON, using the existing eight-tool bridge, executable, argument vector and UTF-8 environment. It gives merge/reopen/check instructions and the appropriate filename/content type. Switching clears the old text and disables copy while generating, so a failed request cannot copy a previous client's configuration. Configuration contains a local private connection-file reference, never the capability token.

`GET /api/v1/mcp/config?endpoint=...` retains its exact generic `mcpServers` wrapper. The optional `client=codex|claude-code|generic` returns a UI artifact envelope (client, filename, content_type, text, instructions); unknown clients receive 400. Connection/proposal contracts and the MCP surface are unchanged. No model-provider or global host settings were changed.

Formats checked against [Codex MCP documentation](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) and [Claude Code MCP documentation](https://code.claude.com/docs/en/mcp), accessed 2026-10-03. These are protocol/setup references; no external implementation code was copied.
