## 问题与改动

`manuscriptRows` 在每个改动的 footer 中重复生成整批应用按钮，但点击发送的是该 Proposal 下全部勾选的 change IDs。空白正文的新段落又都使用原文插入位置 0 编号，导致截图上每段都是 01，并把不存在的旧文显示成红色空栏。这些问题来自模板；定位到直接原因后，没有开展无关的网络或性能排查。

每场候选现在只有一条审查工具栏，集中显示选择数量、全选、放弃和应用。工具栏在审查区滚动时保持可达，位于章节操作栏下方；逐段保留勾选和“继续调整这处”。插入段落按新稿中的位置编号，已有正文的替换/删除继续按原文位置显示完整对比，周围正文顺序保留。

空白正文上的初稿直接呈现单栏新稿，省去空旧文和重复色块；候选待确认时不再同时显示“开始写作”空状态。首次教学跟随实际展示：初稿提示“读一遍新稿”，已有正文仍提示比较改前改后，并指向上方的应用操作。同步更新资源版本。

保持既有显式采用 API、版本校验、选中 change IDs 和正式修订行为。未勾选时禁用应用，阅读/编辑切换不把候选写入本地草稿或建立修订。没有新增依赖、接口、持久化字段或后端修改。
