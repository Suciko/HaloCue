## 完成的行为

1. 未选作品时，资料一级分类直接提供「人物卡」入口。留空检索自动展示实际随包的 102 份人物参考，支持角色名/别名搜索；数量来自目录接口，不是固定展示文案。
2. 点击「查看完整人物卡」可读人物核心、性格、行动、声音样本、情绪、关系和误写提醒；支持返回原搜索结果及失败后重试。该浏览路径只读取随包文件，不创建作品，也不打开导入对话框。
3. 有作品时继续使用原来的作品资料导航和显式导入/审阅流程。背景、表情等素材没有被加入全局人物库。
4. 使用现有浅色/深色主题变量。桌面两列，窄屏一列；档案沿用现有完整参考渲染器。结构化人物核心现在显示可读摘要，不再显示 Python 字典文字；档案补充了身份、学园、公开形象等字段的中文标签。
5. 恢复新作的必要范围引导：先沿用当前要求和整体对话中的篇幅、人物、风格；缺少篇幅/连载意图时可以自然问短篇、长篇/连载或先试写。已明确的信息不再问，直接写/试写不被长度问题阻断，试写小场景不等于把整部作品定为短篇。
6. 修正上一轮按需工具调用暴露的一处状态投影：自然语言创建作品后，系统已有持久化输入快照与摘要时，「准备本轮创作上下文」可以完成，不要求 Agent 再调用一次读取工具。没有实际快照或工具回执时仍保持未完成，不伪造工具记录。

新增 UI 复用 `/reference-characters/search` 和 `/reference-characters/{id}/file` 的只读接口。没有新契约、数据库迁移、资料复制或卡片原文修改。

## 剧本研究如何影响引导

前一轮阅读了维护者指定的评价结构表、评价标准、数份流量分析及已识别剧本的代表性开头；不是逐篇通读整个资料库，也没有做流量统计。原文、台词和评价文件保留在维护者本地研究目录，未复制进源代码。

- 短日常/喜剧：先有具体场面、不同人物的反应、升级与笑点回扣；引导补人物、看点或收尾，避免先要求宏大主题和成长弧。
- 关系向：看谁主动、谁回应、互动之后关系发生什么变化，避免用解释感情的长台词代替行动。
- IF/OC/穿越：接住作者给出的二创前提，处理本作自洽与边界，不自动纠回官方主线。
- 长篇/严肃向：逐步确认持续目标、因果与后续展开空间，不让篇幅选择替代具体创作。

篇幅与题材是独立维度，喜剧也能是长篇。上一轮的自然讨论/按需工具规则继续有效，本轮只补回缺失的范围引导。
