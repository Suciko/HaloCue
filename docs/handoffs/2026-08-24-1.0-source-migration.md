# 1.0 Source Migration Handoff

- Status: first source slice migrated locally
- Branch: `feature/1.0-runtime`
- Scope: 08 production, 09 writing, 10 integrated runtime

## Migrated layout

```text
services/halocue/production/
  src/halocue_production/
  ui/
  tests/
services/halocue/writing/
  src/halocue_writing/
  web/
  docs/contracts/
  tests/
services/halocue/integrated/
  src/halocue_integrated/
  static/
  tests/
```

The integrated runtime now imports the sibling production and writing packages
instead of adding the archived `08` and `09` directories to `sys.path`.
Default runtime state is under the ignored repository `.halocue/` directory.

## Compatibility boundary

The production adapter loads the maintained 0.9 compatibility modules from the
repository root by default. `HALOCUE_LEGACY_ROOT` can point to another explicit
local compatibility checkout. The missing `portrait_layout` compatibility
module and its metadata catalog were added to the root compatibility surface;
no AA database or game asset was copied.

## Excluded from Git

- `data/`, `output/`, `artifacts/`, logs, pytest/browser caches
- AA/BA databases, resource indexes, models, voices, textures, Spine files,
  archives, and user projects
- The external `ba-writing` Skill, official character cards, and research
  material; configure it with `HALOCUE_BA_WRITING_SKILL_DIR` on a local machine

## Verification

```text
PYTHONPATH=services/halocue/production/src
pytest services/halocue/production/tests -q
84 passed

PYTHONPATH=services/halocue/integrated/src;services/halocue/writing/src;services/halocue/production/src
pytest services/halocue/integrated/tests/test_gateway.py -q
9 passed
```

The writing service's contract and presentation tests pass without the external
Skill. Tests that exercise real BA writing prompts remain environment-dependent
and fail closed when `HALOCUE_BA_WRITING_SKILL_DIR` is not configured. This is
intentional; the repository must not embed user or copyrighted writing data.
