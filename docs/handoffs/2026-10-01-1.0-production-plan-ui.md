- Scene cards are shorter; background and review actions are adjacent, exact source evidence moves to an expandable footer, all other material actions remain available. Existing listeners and scene identifiers are moved rather than cloned.
- Failed/interrupted tasks show a readable reason and actionable recovery guidance immediately. Stopped jobs hide stale progress; running annotation still does not claim the current chunk is a completed percentage.
- Requests, usage and raw errors live inside a closed “运行详情” disclosure. Unreported metrics are omitted; a single truthful empty state replaces eight repeated unknown cells. Reported zero remains a real value.
- Removed the duplicate resume button from the task card; the existing primary action still owns checkpoint resume/new-strategy generation. Pause/cancel remain near a running task.
- Theme variables replace the hard-coded white progress rail and status badge backgrounds. Scene list, strategy cards and gate rows use more compact spacing; narrow screens stack the two panels.
