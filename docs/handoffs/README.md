# Collaboration handoffs

Create one Markdown handoff for each collaborator delivery or school-break
checkpoint. Include the commit/PR, changed contracts, migrations, tests and
results, known issues with issue numbers, local commands, and decisions needing
confirmation. Handoffs are durable project records; do not paste API keys,
private paths, game assets, or raw model prompts.

Use `docs/agents/long-term-memory.md` for the start/end session checklist and
the collaborator feedback route. A handoff records session state; it does not
replace an accepted ADR, product direction, contract, or test.
