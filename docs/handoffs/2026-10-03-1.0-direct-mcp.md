## Delivered and governing decision

The maintainer rejected requiring task creation/export/import for normal MCP
use and requested a lighter interface. Settings now authorizes selected works
once; the external host uses four tools from its own conversation: find scenes,
read prose, search material, and propose numbered paragraph replacements.
A read ID hides revision IDs, exact hashes and the pending-candidate ID on the
service. Reading automatically selects current pending prose for refinement.
The original manuscript only changes after author acceptance in HaloCue.

The backend reuses existing scene window/edit tools, validation and atomic
proposal commit. Connections persist through restart, can be revoked, and are
revoked after restoring a backup. Scoped read snapshots and edit receipts are
additive tables. Private capability files stay outside backups. The earlier
single-task bridge is retained for compatibility; its setup button is removed
from task exchange. The nearby file entry is labeled task-package exchange and
is a fallback for hosts without MCP.
