## Result

The official CLI app-server can generate writing proposals and text AA direction
using a managed ChatGPT login. The user completed login and confirmed extra paid
usage was disabled. No normal Codex credentials were copied. The acceptance
runtime was isolated from the user's original production application and data.

The existing model settings workspace now contains login state, quota, model,
extra-usage acknowledgement, purpose selection and activation together. Codex
and legacy API forms are mutually hidden/inert. Strict subscription mode filters
the picker to Codex and rejects legacy transport dispatches server-side. Saved
profiles remain available as records. Partial writing/direction activation
reports the actual state. Existing colors/type/spacing were retained; repeated
heading copy and inherited form padding were removed. Native radios/checkboxes
align with their labels in both desktop and narrow layouts.
