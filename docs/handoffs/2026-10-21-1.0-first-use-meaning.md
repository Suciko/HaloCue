## 目标及发现

接续[完整 AI/恢复交接](2026-10-20-1.0-first-use-ai-recovery.md)，本轮限定为首次创作的理解与操作障碍；产品边界仍见[方案第 0 节](../1.0-guided-workflow-plan-2026-10-19.md#0-同日纠正与当前交付边界)。

Web Control 从零作品走到方向采用后，发现教学直接指向章节大纲，没有接上助手安排场景的输入，也没有说明刚保存的是方向。方向候选与结构候选共用笼统文字；正文应用提示未解释它本身就是保存，取消全部勾选后仍催促点击禁用的“应用”。这些都是执行者可复现的问题；不据此推断真人已经理解。

## 当前行为

- 方向与结构候选分开说明：方向核对人物、冲突和结尾；结构核对每场安排，采用后建立目录和空白场景。
- 已确认方向、还没有场景且未选手写时，点亮构思输入框，请作者描述第一场并让助手整理章节/场景。离开构思讨论时点亮真实返回入口；主动进入章节大纲仍可手动添加场景。“先自己写”可从这一步切回手写路线。
- “保存本场上下文”解释为保存资料选择；手写的“保存整章”解释为保存本章正文改动；AI 正文的“应用”说明只保存勾选部分、应用后即形成正式正文，无需再按保存。
- 读实际场景审查勾选状态，零勾选时提示先选文字；重新选择后恢复应用说明。教学完成条件仍为真实新正式修订，未引入点击计数或自动采纳。
- 沿用现有遮罩、高亮和小指针，不新增教学卡片、视觉系统、依赖、后端工具或持久化格式。`index.html` 更新教学脚本缓存版本。

## Web Control 实操

独立空数据目录：新建“提示灯的第一夜”→ 模拟超时后的真实重试 → 方向候选及采纳 → 按新提示发送场景安排 → 结构候选及采纳 → 进入第一场 → 选择两张合成人物卡并保存范围 → 场景助手起草 → 实际取消全选，教学改为先选文字 → 只勾选两项中的一项并应用。正文显示第 1 版且只有所选一段，遮罩退出；刷新后正文保留且教学不再出现。最终 console warn/error 查询为 0。
