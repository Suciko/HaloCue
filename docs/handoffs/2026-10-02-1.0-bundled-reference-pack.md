three losslessly compressed official scenario JSONL shards: 368,032 records.

face/dialogue examples. 113 payload files have compressed/original SHA-256 and
byte counts. The extraction provenance and incomplete mappings are retained.
These references retain original rights and are not covered by code MIT.

The Git index/export allowlist and PyInstaller data list include the pack.
`.gitattributes` preserves its exact original bytes across CRLF/LF checkouts.
Release scanning reads compressed JSON/JSONL contents with bounded streaming.
Only the three named shards receive a 64 MiB ZIP member size limit; other
archive limits remain unchanged.

Writing defaults to bundled corpus while explicit overrides retain precedence.
Read-only character search/file endpoints use enumerated IDs. The existing UI
search displays curated cards and opens the validation dialog. Explicit import
uses the existing version-checked flow; reading/searching does not alter works.
Actual browser testing caught percent-encoded Chinese IDs; fixed URL decoding.
Full card data stays in the mother card; prompt projection still selects only
scene-relevant material. No paid model calls were needed.
