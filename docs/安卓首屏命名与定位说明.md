# HaloCue 安卓首屏命名与定位说明

- 日期：2026-08-10
- 适用基线：Android `0.3.0-dev`
- 交接对象：正在迁移 HaloCue 安卓端的开发 agent

## 一句话决定

安卓桌面名称继续使用 `HaloCue`；应用首屏以 `HaloCue` 为主标题，以 `AA 剧本自动演出工具` 为中文副标题。不要把桌面名称改成长中文，也不要修改包名和已有数据路径。

## 首屏精确文案

当前 `app/src/main/assets/index.html` 的首屏标题是“手机端剧本生成”，应调整为：

```html
<p class="eyebrow">HALOCUE FOR ANDROID</p>
<h1>HaloCue</h1>
<p class="intro">AA 剧本自动演出工具</p>
```

页面 `<title>` 使用：

```html
<title>HaloCue｜AA 剧本自动演出工具</title>
```

在首屏主操作区附近保留一条与真实能力一致的说明：

> 当前版本支持在本机生成、导出和分享 `.aap`；生成结果尚未导入原版 AA。

这条说明可以随着真实状态动态呈现，但不能在尚未导入时显示“导入成功”。

## 桌面名称与技术标识

以下内容保持不变：

| 项目 | 固定值 |
|---|---|
| Android 桌面名称 | `HaloCue` |
| `app_name` | `HaloCue` |
| Application ID | `com.halocue.android` |
| Gradle 工程名 | `HaloCueAndroid` |
| 公共导出目录 | `Download/HaloCue/` |
| JavaScript 全局对象 | `window.HaloCueApp` |
| Native Bridge | `window.HaloCueNative` |

`app/src/main/res/values/strings.xml` 当前已经是正确值：

```xml
<string name="app_name">HaloCue</string>
```

不要把它改成 `HaloCue｜AA 剧本自动演出工具`。Android 启动器通常无法完整显示这么长的名称，桌面只保留品牌名即可。

## 当前能力边界

Android `0.3.0-dev` 已经完成：

- 在应用内输入工程名和剧本文本。
- 在手机本地生成真实 `.aap`。
- 发布到 `Download/HaloCue/`。
- 调用系统分享面板分享生成文件。
- 检测并打开用户安装的原版 AzureArchive。

当前尚未完成：

- 电脑端完整 WebUI、模型配置、草稿和素材能力迁移。
- AI 演出标注完整流程。
- AI 剧本正文创作。
- 自动写入原版 AzureArchive 的受限工程目录。

因此首屏和发布文案不得使用以下说法：

- `AI 自动写剧本`
- `一键自动导入 AA`
- `已自动安装到 AA`
- `与 Windows 版功能完全一致`

可以使用：

- `本地生成工程文件`
- `导出到 Download/HaloCue/`
- `分享工程文件`
- `打开原版 AA`
- `已生成，尚未导入原版 AA`

## 后续完整迁移后的处理

当电脑端现有的剧本导入、演员与素材核对、AI 演出标注、人工审查和编译流程已经在安卓真机上完整验证后，副标题仍可继续使用 `AA 剧本自动演出工具`，不需要再次改品牌。

只有当“AI 剧本正文创作”已经成为公开、可用并经过验证的功能时，才考虑把中文副标题升级为 `AA 创作工具`。主品牌、包名和数据路径仍保持不变。

## 实施验收

- Android 桌面图标下显示 `HaloCue`，没有长名称截断。
- 首屏首要文字是 `HaloCue`，附近可见 `AA 剧本自动演出工具`。
- 360dp 宽度下标题、副标题和状态说明不重叠、不溢出。
- TalkBack 能按“品牌名、中文定位、当前能力状态”的顺序读取首屏。
- 生成完成后仍明确显示“尚未导入原版 AA”。
- `com.halocue.android`、`Download/HaloCue/` 和现有用户数据不发生迁移。
- 修改后运行现有单元测试、真机仪器测试与页面文本契约；命名调整不能破坏生成、导出、分享和打开原版 AA 的流程。
