## 跨样本稳定规律

### 1. 官方并不是单一的“对白立绘模式”

不同样本的无对白命令节点比例差异很大：

- Code:BOX 发现段：92/148 条记录带有无对白命令；
- 主线 1-1：37/56 条记录没有对白，且主要由旁白、背景、镜头和长等待驱动；
- 主线 3-1-7：35/75 条记录没有对白，主要承担黑屏、重建、特写和情绪停顿；
- 活动 801-2：81/179 条记录没有对白，并且包含视频、弹出图、背景效果和大量旁白。

因此“无对白”不能只理解为人物表情。官方的无对白节点至少分为：

1. 人物反应；
2. 物件操作或反馈；
3. 走位和构图重建；
4. 黑屏/淡入淡出/场景转场；
5. 旁白、屏幕文字和流程控制；
6. 背景效果、音效或视频控制。

### 2. 站位有两种不同机制

同一互动关系内，官方会使用 `m1`-`m5` 让已经在场的人真实移动。活动 801-3 的移动命令最多，
Code:BOX 发现段、3-1-7 和活动 801-2 也有连续的让位/重排。

另一种是整组重建：先 `all` 或转场清除旧镜头，再用 `a/al/ar` 在新槽位建立人物。这不能被解释成
同一角色瞬移，也不能把普通清镜当成真实退场。

### 3. 真实退场是少数语义事件，视觉消失则很常见

`d/dl/dr` 在多段官方数据中出现，但它只证明立绘的消失类命令。`all`、`hide` 和整组转场也会让人物从
当前画面消失，却不等于人物离开剧情空间。

只有文本或视频明确表达离开、退场、冲出等事件时，才能把它解释为 `exit`。否则应视为镜头清除、切换
或重建。Code:BOX 告别段和活动 801-3/801-4 的消失类命令，适合用来研究“视觉离镜”和“叙事退场”的区别。

### 4. 特写的使用频率取决于剧情类型

3-1-7 片段有 34 次 `closeup`，主线 1-3 有 18 次；羁绊 Rank 2 只有 2 次，活动 801-4 只有 3 次。
这说明特写不是固定配额，也不是所有情绪都必须放大。它通常服务于：

- 单人情绪峰值；
- 重要解释或推断；
- 关系确认；
- 场景从群像收束到单人。

### 5. 动作和表情经常分阶段组合

跨样本反复出现的组合包括：

- `em + stiff`：尴尬、僵住、犹豫或压力；
- `em + shake`：更强烈的惊讶或慌乱；
- `em + hophop`：兴奋、欢呼、行动冲动；
- `em + greeting`：积极回应、确认或礼貌承接；
- `a + em`：新构图显现时立即承载情绪；
- `closeup + em`：把情绪峰值交给单人主体；
- `d + wait`：视觉消失后保留一段余波或转场时间。

但同一段中也存在只换 face、只执行动作、只改变站位或只等待的节点。官方没有要求每个节点同时堆
face、emo、act。

### 6. Wait 的语义不是统一的“停顿”

跨样本出现了 100ms、500ms、600ms、700ms、800ms、1000ms、1200ms、1300ms、1500ms、2000ms、2500ms、
3000ms、3500ms、4500ms、5000ms、6000ms、6500ms 等多种时长。

- 100-500ms 通常是动作或镜头衔接；
- 800-1500ms 常见于反应、观察、验证和短暂沉默；
- 2000ms 以上常见于明显情绪停顿、独白留白、黑屏或场景转换；
- 主线 1-1 的长等待和旁白密集，说明官方还有“环境/叙事节奏”类型，而不只是角色反应。

连续相同动作配不同等待时长不能去重。例如 Code:BOX 的 `stiff + 1200/500/500/700ms` 是逐步推进的
心理节拍，不是真重复。

### 7. 不能把标点直接映射成固定资源

官方会把省略号、问号、感叹号、惊疑等信号放在对白、无对白气泡、动作、特写和等待的不同组合中。
同一个标点在不同剧情阶段可能只换脸，也可能触发气泡、动作、单人切镜或静默等待。

正确的抽象是：

```text
当前阶段相对于上一有效节点发生了什么变化？
这个变化需要 face、emo、act、镜头、站位还是等待来表达？
```

而不是：

```text
看到问号就加问号气泡；看到感叹号就加 jump。
```

## 研究边界

本轮已经比先前的 Code:BOX + 3-1-7 两个样本更广，但仍然是“分层抽样研究”，不是对 36.8 万条官方记录
逐条人工观看。原始解析器保留了全部记录和命令；后续应继续从主线、羁绊、活动中补齐视频/人工证据，尤其是：

- 真实入场和真实退场；
- 黑屏、淡入淡出和交叉渐变的视觉边界；
- 旁白/屏幕文字主导的长节奏；
- 视频、弹出图和背景效果；
- 多人群戏的持续站位和关系距离。

只有跨多个独立官方样本反复出现的规律，才可以进入通用提示词或后端规则。单个样本只作为例证，不能升级为
硬模板。
