# HaloCue 1.0 Beta 2

本版延续 [Beta 1](1.0.0-beta.1.md) 的写作、资料、定稿交接和 AA 制作功能。
完整源码与 Windows 便携包以 `v1.0.0-beta.2` GitHub Release 为准。

## 本版修复

- 随包提供 102 份完整人物参考卡与 368,032 条官方演出记录，含指令、资源、审计与表情台词示例索引。资料页支持检索并明确导入完整人物卡；原作语料默认可读，不再依赖维护者本机路径。详见 `data/reference-pack/README.md`。

- 新增背景覆盖素材时，预览立即采用覆盖文件，不依赖 Windows 目录时间戳是否变化。
- 公开源码与便携包包含 ECharts 的 LICENSE、NOTICE 和第三方声明；缺失时构建会失败。
- 连续规划的测试等待前一轮后台 Agent 结束，保留程序对并发请求的保护。

Windows 包为 `HaloCue-1.0.0-beta.2-windows-x64.zip`，完整解压后运行 `HaloCue.exe`。
版本 metadata 为 `1.0.0-beta.2`，Python distribution version 为 `1.0.0b2`。
升级前备份 `%LOCALAPPDATA%\HaloCue`，集成界面通过下载新包手动升级。

## 验证与边界

背景预览回归固定文件系统签名，覆盖新增优先、删除回退及并发缩略图解析。
相关预览测试 13 项通过，Ruff check/format 检查通过。
最终三版本 CI、打包与实际 EXE 验收结果须以发布记录和 PR #40 为准；准备记录不等于通过。

原生 AA 动画、音频和时序、各用户的资源环境、完整旧数据迁移仍需专项验收。
桌面宿主为 WebView2，Electron 原生窗口控制未接入。外部环境与跳过项不算已通过。
API 由用户配置；密钥、作品和游戏资源不随包分发。Beta 保留稳定更新入口，通过手动下载升级。
