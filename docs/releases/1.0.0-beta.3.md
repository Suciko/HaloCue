# HaloCue 1.0 Beta 3 本地预览包

本轮基于 Beta 2 后的当前 1.0 源码打包，尚未发布 GitHub Release。

- 加入 Codex 订阅连接，以及外部 Agent 直接读取正文、资料和 AA 制作任务、提出待审修改的 MCP 工作流。
- 设置中可选择 Codex TOML、Claude Code JSON 或通用 MCP 配置。
- Windows 包带有独立 `HaloCueMCP.exe`，Agent 连接无需 Python 或源码目录；HC 需保持运行。
- AA 演出建议显示前后对比，作者决定采用或拒绝；Agent 不直接采用、编译或安装。

完整解压 `HaloCue-1.0.0-beta.3-windows-x64.zip`，运行 `HaloCue.exe`。
保留同目录的 `HaloCueMCP.exe` 与 `_internal`，不要只复制主 EXE。
升级前备份用户数据；旧包及其数据不由打包过程覆盖。

Codex/Claude Code 客户端及账号由用户自行安装和登录；MCP 桥接不运行模型。
Claude Code 官方登录过期的模型联调仍待恢复账号后完成。
本地包验收结果见本轮交接记录；未完成的正式发布、原生 AA 动画/音频验收不算通过。
