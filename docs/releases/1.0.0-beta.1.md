# HaloCue 1.0 Beta 1

候选标识：`v1.0.0-beta.1`。这是预发行候选，供测试使用。
发布状态以 GitHub Release 和 `main` 的合并记录为准。

## 随包功能

- 写作工作台：构思讨论、章节与场景正文、人物和世界资料、聊天提出修改、逐段审阅与明确采纳。
- 资料检索：随包公开写作规则与 BA 人物、背景、外观和表情元数据；用户可另行接入自己的原作摘录库。
- 定稿交接：审查门禁、不可变发布快照、关联制作任务、重复交接保护。
- AA 制作：导入与场景判断、角色与素材映射、AI 演出生成、审查、编译与安装适配。
- 本地能力：资源导入、自定义素材、后台任务恢复、反馈、备份恢复及旧版本兼容入口。

元数据不包含游戏图片、音频或骨骼。API 连接由用户在设置中配置，密钥不随程序或源码分发。

## 完整源码

Git 仓库保留当前产品源码、三个本地服务、网页资源、兼容适配器、公开写作规则、脱敏数据、测试、构建脚本与协作文档。
开发中的其他版本目录只是各自的边界，不作为 1.0 Beta 已实现功能宣传。
本地验收数据、构建物、缓存、备份和私人配置不进入 Git。

从源码运行（建议 Python 3.13；项目测试覆盖 Python 3.10–3.13）：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python launcher.py
```

开发验证：安装 `requirements-dev.txt` 和 Playwright Chromium，然后运行 `python -m pytest -q`。
默认测试发现明确覆盖兼容、制作、写作与集成四套测试，不扫描本机备份和构建快照。

## Windows 便携包

预计发布附件为 `HaloCue-1.0.0-beta.1-windows-x64.zip` 与 SHA-256 校验文件。
实际附件以上传后 GitHub Release 为准。完整解压后运行 `HaloCue.exe`，无需自行安装 Python。
当前桌面宿主为 WebView2；没有将本次发布描述为 Electron 版本。
配置与作品默认保存在 `%LOCALAPPDATA%\HaloCue`，升级前请备份该目录。

## 已验证与限制

前一轮使用官方 51 段剧情验证导入、保存、冻结定稿、制作交接、备份恢复与重启保留。
四套全量测试及失败项复测形成 4071 项通过、16 项跳过的记录；这不是一次同时全绿的运行。
本次 Beta 元数据、品牌修正与真实打包还需要本次发布验证记录，以最新 handoff 为准。

本地模拟验证流程，不能替代真实模型质量评价。原生 AA 动画、音频和时序、各用户的资源环境、完整旧数据迁移仍需专项验收。
Electron 原生窗口按钮尚未接入。缺失的外部环境和跳过项不视为已通过。

Beta 使用 GitHub 预发行标识，保留现有稳定更新入口；集成界面目前通过下载新包手动升级。
不伪造自动更新签名，也不将预发行包替换为 GitHub 的最新稳定版。
