# HaloCue 1.0 用户手册

如果你想按页面查找，请先打开[手册目录](manual/README.md)。本页保留完整的连续阅读版本。

这份手册面向 Windows 用户。HaloCue 是本地优先的剧情制作工具：它保存作品、章节、场景和正文修订，允许 AI 提出候选，再把用户确认后的定稿交给 AzureArchive 制作。

## 先记住三件事

1. AI 只提出 Proposal 或审查 Finding，不会静默改写正式正文。
2. 正式发布前必须经过人工确认；ScriptRelease 冻结后不可变。
3. Spine、AzureArchive、游戏资源和模型 API Key 都由用户自行准备，公开包不包含这些内容。

## 5 分钟完成第一场

1. 解压 `HaloCue-1.0.0-windows-x64.zip`，双击 `HaloCue.exe`。不要直接从压缩包预览窗口运行。
2. 首次启动时选择你自己的 `AzureArchive.exe`。HaloCue 会读取 AA 的工作区设置，不要选择 HaloCue 文件夹或某个存档文件。
3. 在“作品”中建立作品，确认全作方向，然后建立卷、章和第一场。
4. 在“正文”中输入对白和旁白。推荐一行一个说话者，例如 `老师: 久等了。`。
5. 需要 AI 时，在“设置 → 模型接口”添加模型并先点“测试文字”。不需要 AI 时可以使用“仅转换格式”。
6. 生成候选后逐项阅读 Diff，选择“应用”才会建立新的正式 Revision；不满意就退回。
7. 在“发布”执行场景审查、连续性审查和发布审查。所有 Gate 通过后冻结 ScriptRelease。
8. 切到“AA 制作”，确认角色映射、背景和音效，逐卡审查，先“检查问题”，再编译和安装。

## 写作工作台

### 细纲

细纲管理章节与场景顺序。场景是 Agent、上下文、正文和素材引用的稳定边界。全作方向未确认时，新增卷章或正文会被锁定，这是保护作品一致性的正常门禁。

### 正文

正文由稳定的段落块组成。手工保存会创建不可变 Revision；旧版本仍可比较。模型生成的内容始终先进入 Proposal/Diff，只有用户采纳才进入正式正文。

### 资料与记忆

人物卡、世界观资料、WorkCanon 和长期记忆都有来源与可信状态。待审资料不会自动进入后续场景；只有确认后的记忆才会参与上下文。资料变化会让相关审查 Gate 失效，并要求重新审查。

### 失败、重试和冲突

网络错误、429、5xx 和临时超时可以从固定输入快照重试。配置或正文在任务期间发生变化时，旧任务不会被伪装成成功，界面会要求用当前版本重新开始。取消任务后，迟到的模型结果不会写入作品。

## AI 模型

- **Fake / 模拟**：仅用于协议和界面测试，不能当作真实模型结果。
- **真实 Provider**：必须先测试连接；API Key 由 Windows 安全存储，不进入正文、截图、日志或 Proposal。
- 模型切换不会改变已经运行的 Agent；如果配置摘要变化，失败任务需要按当前模型重新发起。
- 模型不可用时，依赖模型的按钮会显示阻塞原因；“仅转换格式”仍可使用。

## AA 制作

1. 在设置中连接 AzureArchive 工作区。
2. 从 AA 资源索引选择角色、背景和音效；搜索结果只显示稳定标识，不暴露物理路径。
3. 自定义素材先导入“我的素材”，填写 AA 中登记的真实 Identifier。每个制作任务使用冻结副本。
4. 角色映射只影响当前任务。背景请求和音效请求必须通过专门的“选择/移除”流程解决，不能删除卡片绕过 Gate。
5. 编译前先执行“检查问题”。编译成功后可以安装到 AA；同一 Build 重复安装会被拒绝，避免覆盖工程。

公开版不包含 Spine。需要骨骼预览或表情分析时，在设置中选择你合法安装的 Spine 命令行程序；普通剧本导入和编译不受影响。

## 文件、备份和换电脑

便携程序目录只放程序文件。用户数据默认在：

```text
%LOCALAPPDATA%\HaloCue
```

退出程序后复制整个目录即可备份。恢复前先把当前目录改名保留。换电脑时先启动新版本，再重新选择新电脑上的 AzureArchive 路径，不要直接复制旧电脑的绝对路径配置。

### 0.9.3 到 1.0

1.0 首次启动会检测旧版数据并生成迁移状态。迁移前先备份；向导只复制已知文件，不覆盖已经存在的 1.0 文件。无法转换的内容会列出原因。迁移失败时原目录保持不变，可从带时间戳的备份恢复。

## 自动更新

启动后 HaloCue 会在后台检查签名更新清单，网络超时不会阻止本地工作。发现新版本时只显示通知。点“下载并校验”后，程序会验证 HTTPS、Ed25519 签名、大小和 SHA-256；下载完成后再点“退出并更新”，由独立更新器替换程序并重新启动。替换失败会恢复旧版本。更新过程不会修改 `%LOCALAPPDATA%\HaloCue` 中的作品数据。

也可以在命令行执行：

```powershell
HaloCue.exe --check-update
HaloCue.exe --no-update
HaloCue.exe --download-update   # 高级用法：下载并安全解压到 staging
```

下载完成后先退出 HaloCue，再运行包内的 `HaloCueUpdater.exe`，把输出中的
`staged_root` 作为 `--staged-root`、当前程序目录作为 `--install-root`，并传入
主进程 PID。更新器只替换程序文件，不触碰用户数据。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| 应用窗口没有打开 | 退出其他 HaloCue 实例；确认安装 Microsoft Edge WebView2 Runtime。 |
| 找不到 AA | 重新选择真实的 `AzureArchive.exe`，不要选存档文件。 |
| 找不到 Spine | 公开版不附带 Spine；只有需要骨骼功能时才配置自己的合法安装。 |
| 模型连接失败 | 检查地址、模型名和 Key，先执行连接测试；不需要 AI 时切换到仅转换格式。 |
| 素材库不可用 | 确认 AA 工作区在线，稍后刷新；不要手工填写物理路径绕过目录校验。 |
| 更新失败 | 保留旧版本，检查网络、磁盘空间和安装目录写权限；可手动下载对应 Release。 |
| 迁移失败 | 不删除旧目录，打开迁移状态报告，从时间戳备份恢复后再重试。 |

## 当前不包含

MMT/视频优先的 1.1 工作流、AI GalGame 动态行为和任何第三方游戏资源不属于 1.0 公开包。它们不会因为界面出现规划文字就自动成为 1.0 功能。
