# HaloCue 1.0.0 完整交付包说明

日期：2026-09-26

## 这个包是什么

这是 HaloCue **1.0.0 Windows x64 便携包**：当前 1.0 写作工作台、资料卡、Proposal／审查门禁、活动与反馈、AA 制作入口、资源导入／匹配、编译／安装适配器、迁移和更新检查会一起编译进 `HaloCue.exe` 与 `HaloCueUpdater.exe`。解压后双击 `HaloCue.exe`，不需要安装 Python。

包内同时保留 1.0 的兼容边界：

- 旧数据迁移状态与备份／导入入口；
- 0.9.3 旧用户目录的显式迁移适配；
- 0.95/AA 资源、工程和制作行为的兼容适配器；
- `HaloCue.exe --legacy-ui` 兼容制作界面入口；
- 1.0 新的写作／资料／制作工作台和本地服务。

这不是把 0.95 的完整历史 Git checkout、私人 `aa_assets.db`、游戏资源、Spine、个人工程或旧版安装包塞进 1.0。0.95 的角色是**兼容输入和迁移来源**；当前产品身份是 1.0.0。

## 第一次启动

1. 完整解压 `HaloCue-1.0.0-windows-x64.zip` 到新的文件夹。
2. 双击 `HaloCue.exe`。
3. 在设置或首次检查中选择你自己合法安装的 AzureArchive 工作区／程序。
4. 旧数据迁移前先备份；迁移不会静默覆盖已有 1.0 数据。
5. 没有 AA 或模型时，仍可浏览工作台、写作和整理资料；制作相关能力会如实显示缺少的外部环境。

用户数据默认位于 `%LOCALAPPDATA%\HaloCue`，不写回程序目录。源码验收包使用自己的 `.review-data`，不要把两种数据目录混用。

## 可验证的版本身份

- `版本.txt`：HaloCue 1.0.0 / Windows 10/11 x64。
- `build-manifest.json`：逐文件大小与 SHA-256。
- ZIP 旁车：`HaloCue-1.0.0-windows-x64.sha256.txt`。
- 源码分支、基线提交和 1.0 功能审查记录见配套源码验收包的 `REVIEW_MANIFEST.json` 和 `docs/review/发送前验收结果.md`。

## 外部依赖边界

公开包不包含 AzureArchive、Spine、游戏资源、个人骨骼、个人作品、模型 API Key 或私人配置。需要真实 AA 立绘／表情／背景／声音时，使用者必须在自己的授权环境中导入；包内空资源或脱敏资源索引不是游戏资源本体。

## 兼容性结论

“完整 1.0”表示**1.0 产品运行时和已声明的 0.95/旧数据兼容入口完整随包交付**，不表示旧版私有资产或原生 AA 客户端播放环境随包交付。真实 AA 播放、真实模型质量和特定 0.95 用户数据迁移仍需要合作者用自己的授权环境做专项验收。
